## 四、现状问题诊断（对照数据）

### 中文符号页 `SymbolLayout.CHINESE_ROWS`
```
， 。 、
！ ？ ：
； （ ）
… — ·
```
- **双引号 `“ ”` 只藏在上滑里**（`！→“`、`？→”`），但它们各占 9.2% 标点、排名第 3/4，
  比 `： ！ ？` 都高频 —— 这就是「常用符号难找」的典型。
- `；`（0.15‰，最低）却占主键；`…`（2.31‰）排在更下面。排序没跟频率走。

### 英文符号页 `SymbolLayout.ENGLISH_ROWS`
```
, . ;
! ? :
' ( )
" - /
```
- `;`（3.2‰）占主键，而 `_` 只是 `-` 的上滑，字母区 `_` 已被移出 →
  **「下划线难找」就是这条**。

### 字母上滑
- 中文：`zxcvbnm = ！？《》：；、`，`a..l = -/ : ; ( ) ~ “”`。
- 英文：`_ & %` 被明确「让位退到符号页」——痛点来源之一。

## 五、重排方案（待实施）

### 5.1 中文符号页（按频率）
主键 12 格（剔除功能行）：
```
， 。 、        ← 断句三件套（39.7/22.7/1.27）
“ ” ：        ← 引号提升为主键（各 9.2%，第 3/4）+ 冒号
！ ？ …        ← 4.1/3.1/1.4
— （ ）        ← 破折/括号
```
- `；`（最低）降到上滑；`‘’` `《》` `·` 走上滑。
- 上滑做「同族下一个」：`“→‘`、`”→’`、`！→【`、`？→】`、`（→《`、`）→》`、
  `，→；`、`…→·`、`—→——`(长破折)。
- **必须保证已能打出的符号一个不少**：给中文也加一条 baseline 断言（照
  `英文态基准符号一个都不能少` 的思路）。

### 5.2 英文符号页（按频率 + 编程高频）
主键 12 格：
```
, . '        ← 逗号 61.6 / 句号 65.3 / 撇号 24.3
" - _        ← 双引号 26.7 / 连字符 15.3 / 下划线（编程刚需，提为主键！）
? : !        ← 5.6 / 3.4 / 3.3
; ( )        ← 3.2 / 括号
```
- **`_` 提为符号页主键**，直接解决「下划线难找」。
- `@ # $ & * + = [ ] { } \ | /` 走上滑或保留字母上滑。

### 5.3 字母上滑（英文）
- 保持豆包同款 `a..l = - / : ; ( ) ~ ' "`。
- 第三排 `zxcvbnm`：在 `@ # $ * …` 之外，**把 `_` 塞回一个字母上滑**（候选：`b` 或
  `n`），因为它编程高频且当前无一级路径。若槽位不够，至少保证符号页主键可达。

## 七、追加需求（2026-11-14 12:08，待用户确认）

### 7.1 中英文上滑「同键同位」（用户三次强调）

**原则**：同一个/同一类标点，中英模式必须落在**同一个字母键**上。现状是中文 `z=！ x=？`、英文 `z=? x=!`，`c v b n m` 中英完全错位，肌肉记忆全废。

**统一表（键位固定，中英只换全角/半角）**

第二排 `a s d f g h j k l`（两边都存在，精确同键）：

| 键 | 中文 | 英文 | 类别 |
|---|---|---|---|
| a | — | - | 破折号/连字符 |
| s | / | / | 斜杠 |
| d | ： | : | 冒号 |
| f | ； | ; | 分号 |
| g | （ | ( | 左括号 |
| h | ） | ) | 右括号 |
| j | ~ | ~ | 波浪号 |
| k | “ | ' | 左引号 |
| l | ” | " | 右引号 |

第三排 `z x c v b n m`（中文专属占据键位，英文放同类/高频填充）：

| 键 | 中文 | 英文 | 说明 |
|---|---|---|---|
| z | ！ | ! | 叹号，**同键** |
| x | ？ | ? | 问号，**同键**（修掉旧 bug：英文曾把？放 x 没错但中文也 x，这里统一到 x） |
| c | 《 | < | 左尖括号/书名号 |
| v | 》 | > | 右尖括号/书名号 |
| b | 、 | _ | 顿号↔下划线（**下划线一级路径，解决用户痛点**） |
| n | … | & | 省略号↔与号 |
| m | —(长破折) | * | 破折延长↔星号 |

> 取舍说明：`《》` 对 `< >`、`、` 对 `_` 并非严格同类，但**位置固定**（用户要求「同一个或者同一种」）。`_` 落到 b 键让「下划线难找」在字母区就有一级路径。`@ # $ % + = [ ] { }` 等退到符号页主键（第一屏即可点）。

## 九、复核修正（2026-11-14 12:35）

第 8 节落地后做了一次「改造前后可达集差分」复核，发现三处必须修：

| 问题 | 现象 | 修法 |
|---|---|---|
| 英文 `$` 丢失 | `b` 上滑 `$→_` 后，符号页 `;` 上滑只有 `|`，全键盘打不出 `$` | 符号页 `;` 上滑改 `$`；`|` 挪到 `_` 的上滑 |
| 表情 chip 抢了形码筛选的首位 | 候选条顺序成了 表情→形，违反「形码筛选必须压最左」 | 改为 **形 → 验证码 → 表情 → 箭头** |
| 中文基准断言缺失 | 第八章只承诺未落地 | 新增 `中文态基准符号一个都不能少`；英文那条扩到全 ASCII 标点 |

**可达集定义**（单测 `QwertyLayoutTest.reachable`）：
字母页(本体+上滑) ∪ 符号页(本体+上滑) ∪ **数字页(本体+上滑)**。
数字页中英一致，中文态里 `+ - / : ; %` 等半角符号实际是从数字页上滑打的，
不算进来会出现「假丢失」。

**差分结果**：中文 46 → 47（仅新增 `——`）；英文 41 → 44（新增 `& [ ]`）。**零丢失**。
