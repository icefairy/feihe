# 手动验证清单

发版前照着跑一遍的验收步骤，按里程碑分组。**每一条都对应一个已实现的功能**，
所以它同时也是「怎么手工触发某个行为」的索引——排查时想知道某个路径长什么样，
来这里找对应的操作序列。

不需要全跑：改动碰到哪块就跑哪组。改 `textservice.rs` 的按键路径，M2 + 分词 +
回车那几组必跑；只改文档就一条都不用跑。

---

**M1（骨架）**

1. `build.ps1` 成功，生成 `feihe.dll`，且 `objdump -p` 的导入表里**没有** `libunwind.dll`
2. `register.cmd` 后 `HKCU\Control Panel\International\User Profile\zh-Hans-CN` 出现 `0804:{70CB823D...}{DA6B9170...}`
3. 键盘列表出现「飞鹤拼音」（列表由 shell 缓存，必要时注销重登）
4. 切到飞鹤后，`Ctrl+C` / `Alt+Tab` / `Win+Space` 等快捷键仍然正常（不被吞）
5. `unregister.cmd` 卸载干净，无残留

**M2（输入）**

6. 任意输入框敲 `nihc` → 组合串显示 `nihc`，光标下方弹出候选窗，第一个是「你好」
7. 空格上屏「你好」；敲 `vsgo` + 空格 → 「中国」；敲 `ui` → 候选里第一项「是」
8. 敲 `de` → 候选窗第一页是 的/地/得/德…，按 `3` 上屏「得」
9. 敲 `nih` 后连按 `=`（或 `↓`）能翻页，`-`（或 `↑`）回上一页，`←/→` 能改选中项
10. 敲 `nihc` 后 `Esc` → 组合串消失，文档无残留
11. 敲 `ni` 后退格两次 → 组合态结束，文档无残留
12. 敲到一半按 `Ctrl+C` → 组合串先提交，再执行复制

**用户词库（搜狗导入）**

13. `python tools/import_sogou.py` 输出「最终写入：约 5 万条」，`src/user_dict.txt` 约 1.1MB
14. 敲你平时常用、但基础词库里没有的短语（比如常打的短句），候选窗里能出
15. 用户词排在基础词前面：敲 `de`，如果搜狗词库里有以 `de` 开头的常用词，它应排在「的」之前
16. 反复执行 `import_sogou.py` 两次，`user_dict.txt` 内容一致（幂等）
17. 把 `src/user_dict.txt` 清空后重新构建，发布 DLL 回到 3.0 MB、`base.bin` 38024 条，
    说明没导入时不影响基础功能

**M3（32 位支持 / 长句分隔）**

18. `build.ps1` 默认产出两份 DLL，PE 头分别是 `Machine=0x8664` 和 `0x014c`，
    且两次 `[test] xx : PASS`（LoadLibrary + DllGetClassObject + CreateInstance）
19. `objdump -p` 里两份 DLL 的导入表都**没有** `libunwind.dll`
20. `register.cmd` 后 `HKLM\SOFTWARE\Classes\Wow6432Node\CLSID\{70CB823D...}\InprocServer32`
    指向 `%ProgramData%\Feihe\feihe32.dll`，且 `HKLM\SOFTWARE\Wow6432Node\Microsoft\CTF\TIP\{70CB823D...}`
    有完整的 Category / LanguageProfile
21. 在 32 位宿主里（例如 32 位 Office、`C:\Windows\SysWOW64\notepad.exe`）能用飞鹤打字
22. 打 `vhsjlisi` 时若词库无「张三李四」→ 进分词模式，`←/→` 能移段、数字能换词
23. 全拼模式下打 `nihaoshijie` → 切成 `[你好]世界` 两段（不再是整串挂字母）
24. `xi'an` 能强制切成 `xi`+`an`；`ni'hao` 的分隔符不会出现在上屏文本里
25. 微软双拼下 `;` 仍然出 `ing`，分隔用 `'`

**M3.5（交互打磨）**

26. 鼠标点候选窗里的词 → 直接上屏该项；按下后拖到窗外再松开 → 不上屏（防误触）
27. 点候选窗不会让输入框失焦，点完继续按键仍然进组合态（`WM_MOUSEACTIVATE → MA_NOACTIVATE`）
28. 敲单键 `n` → 候选窗能一路翻下去（一千多条，一百多页），翻到最后一页不会卡、
    也不会重复；敲 `ni` 同理（0.3.2 起候选不设上限）
29. 设置窗勾掉「动态调频」→ 选词后候选顺序不再变化；点「重置」提示清空的条数
30. 打完一轮字后 `%TEMP%` 下**没有** `feihe-trace.log`（诊断日志已移除）
31. 打 `limkyr` 进分词显示 `[李明]远`，按退格 → `[李]明远`（候选变成「李」的字候选），
    再按退格 → 编码退回 `limk`、候选出现「李明」（拆词那一步不丢编码）

**M3.6（农历 / 干支 / 节气 + 用户手册）**

32. 敲 `/nl` → 第一项形如「农历丙午年九月十四」，和手机日历对得上；
    闰月那一年（如 2023 闰二月）会显示「闰二月」
33. 敲 `/gz` → 四柱形如「丙午年 戊戌月 庚午日 壬午时」；立春前后各试一天，年柱会变
    （春节前后试则不变——年柱按立春换，不按春节换）
34. 敲 `/jq` → 给出下一个节气（如「2026年11月7日 立冬」）；当天正好是节气日则给当天
35. 只敲一个 `/` → 8 个命令的当前值预览都能出来，`/nl`/`/gz`/`/jq` 在内
36. 安装目录下有 `使用帮助.md`，用记事本打开中文不乱码（UTF-8 BOM），卸载后一起消失

**M3.7（一级简码 / 手动置顶 / 不弹窗模式）**

37. 敲单键 `d` → 第一个候选是「的」；`u`→是、`v`→这、`i`→出、`f`→发（26 键逐个试）
38. 敲单键 `d` → 候选**全是单字**（不再出现「都是 / 对了」这类两字词）
39. 敲 `de` → 第一个仍是「的」，但这时是词频在起作用，不是一简字
40. 打 `d`，按 `Ctrl+2` 选「大」→ 上屏「大」，且以后 `d` 的第一个变成「大」
41. 再打 `d`，对已经是第一的「大」按 `Ctrl+1` → 取消置顶，`d` 回到「的」
42. `%APPDATA%\Feihe\pinned.txt` 里能看到 `d<TAB>大`；手改成别的词、切一次输入法后生效
43. 设置窗显示「置顶 d→大 · Ctrl+数字 切换」，点「清空」后提示取消的条数
44. 敲 `d` 后立刻按 `Ctrl+C` → 组合串先提交，不误触发置顶
45. 设置窗勾上「不弹窗模式」→ 候选窗和状态浮窗都消失，组合串变成 `nihc  1.你好 2.拟好 …`
46. 不弹窗下空格出第一候选、数字键照样选、`-`/`=` 照样翻页
47. 不弹窗下按 `Ctrl+Shift+U` → 恢复候选窗和浮窗（这是唯一的键盘出口）
48. 关闭后 `config.ini` 里 `no_popup=0`，`config_ver=5`

**M3.8（TSF UILess）**

49. 用 `tools/tsfhost`（见 handoff）跑 `--selftest`：`BeginUIElement > 0` 且候选列表非空，
    候选由**宿主**画出来，飞鹤的候选窗不出现
50. 同一宿主里 `%APPDATA%\Feihe\config.ini` 的 `no_popup=1` 时，候选**不再**往组合串里
    塞一份（宿主已经画了，两份会重复）
51. 宿主返回「你自己画」（普通记事本）时行为不变，候选窗照常弹出

**快捷输入（引导符 `/`）**

52. 中文态敲 `/` → 组合串里出现 `/`，候选是八个命令的当前值预览
53. 敲 `/rq` → 第一个候选是今天的日期；`/r` 效果一样
54. 只敲 `/` 再按回车 → 上屏 `/`（开全角标点则上屏 `／`）
55. 中文态敲 `\` → 上屏顿号 `、`（不再有第二个键出顿号）
56. 敲 `/` 后按数字键 → 选的是候选（八个命令），数字不会被塞进组合串
57. 英文态敲 `/` → 正常出半角斜杠，不弹候选窗

**M3.9（自造词）**

58. 打 `limkyr` 进分词（`[李明]远`），退格拆成单字、选「李」「明」「远」上屏「李明远」
59. 再打 `limkyr` → **第一个候选就是「李明远」**，不用再拆词（`%APPDATA%\Feihe\phrases.txt`
    里出现 `李明远<TAB>li ming yuan`）
60. 切到全拼模式打 `limingyuan` → 同样能出「李明远」（存的是全拼，不是双拼码）
61. 设置窗「动态调频」一栏显示自造词条数；点「重置」→ 提示清空了几个自造词，再打 `limkyr`
    又回到自动分词（`phrases.txt` 只剩表头）

**M3.10（回车 = 字母）**

62. 中文态打 `mmap` → 组合串切成 `[面]ap`（`ap` 没有候选，只能当字母），按**回车** →
    文档里是 `mmap`，**不是**「面ap」
63. 打 `mmap` 再按 `，` → 上屏 `mmap，`（同样不走「面ap，」）
64. 打 `nihao` 按回车 → 上屏 `nihao`；打 `nihao` 按空格 → 上屏「你好」
65. 分词模式里先空格确认一段、再按回车 → 那一段保留汉字，其余段出字母

**M3.11（Shift + 字母）**

66. 中文态按住 Shift 敲 `A` → 文档里直接是 `A`，组合串里没有 `a`，候选窗不弹；
    单独单击 Shift 仍然切中英文（没按别的键）
67. 打 `ni` 再按 `Shift+A` → 上屏「你好A」（组合串先按当前候选结掉，大写粘在后面）
68. `Ctrl+Shift+A`、`Shift+1`（`!`）、`Shift+/`（`?`）仍然原样交给应用，飞鹤不插手

**M3.12（一简次选）**

69. 敲单键 `d` → 第二位固定是「打」；`c` → 第二位「词库」，`j` → 「见」（26 键逐个试）
70. 敲 `d` 再敲 `;` → 直接上屏「打」（次选键），组合串不残留；敲 `c;` → 「词库」
71. 敲 `ni` 再敲 `;` → 仍然是**手动分隔符**（组合串变成 `ni'`），不是次选
72. 全拼模式下敲 `a` 再敲 `;` → 分隔符，不吞成次选

**M3.13（二级简码 = 两键词）**

73. 敲 `nd` → 第一个候选是「难道」，第二位是「奶」（`sy`→所以、`py`→拼音 同理）
74. 敲 `mm` → 第一个仍是「面」，第二位是「慢慢」（次选不抢首位）；`uu` →「书」/「试试」
75. 敲 `vd` → 前两位是「知道」「直到」；敲 `wm` →「我们」（和「完美」都在）
76. 设置里切到微软双拼，敲 `nd` → **没有「难道」**（两键词只在小鹤方案生效）
77. 把 `src/brief2.txt` 里 `nd 难道` 那行删掉重新编译 → 敲 `nd` 不再出「难道」（数据驱动，不用改代码）

**M3.14（编译个人词库）**

78. 全新安装（`%APPDATA%\Feihe` 下没有 `user_dict.txt`）→ 设置窗点「编译个人词库」 →
    提示「还没有个人词库。先用「导入词库…」导入一个词表。」，**不出现任何「找不到文件」**
79. 导入一个词表后再点一次 → 「已编译 N 条到 user.bin（xx KB）」，`%APPDATA%\Feihe\user.bin` 存在
80. 导入后删掉 `user_dict.txt` 再点 → 「没有 user_dict.txt，现有 user.bin N 条，无需编译。」
81. 手改 `user_dict.txt`（加一行）但不点按钮 → 打那个词能出（自动退回文本覆盖层）；
    点一次「编译个人词库」→ `user.bin` 的 mtime 变新，重启输入法后仍能出

**M3.15（右键置顶 + 学习不越级）**

82. 敲 `ig` → 第一位是「成」（不论 `freq.txt` 里「程序」记了多少次）；
    敲 `igxu` → 第一位是「程序」（同键数内学习照常生效）
83. 敲 `d` 出候选窗，**右键**点第 3 项（比如「到」）→ 该项跳到第一位，组合串不变、
    光标不动、没有字上屏；再右键点它一次 → 回到原位
84. 在浏览器地址栏敲 `de`，右键点想要的候选置顶 → 生效（`Ctrl`+数字 在这里会被
    浏览器拿去切页签，收不到）
85. 右键点候选后按空格 → 上屏的是**置顶后的第一位**，不是右击那一项
86. 全屏游戏（UILess）里右键点候选无效——候选是游戏画的，没有我们的窗口
87. 敲任意码后**快速**点候选再立刻把鼠标移开——上屏的仍是点中的那一项
    （命中用的是消息自带的坐标，不是「处理消息时的鼠标位置」）
88. 左键点候选：按下后**在窗口内**松开才上屏；按下后拖到窗口外再松手 → 不上屏、组合态保留
    （这条以前恒失败：`ReleaseCapture()` 早于命中判定，把 `pressed` 自己清掉了）

**M3.16（全屏自动收起候选窗）**

89. 正常桌面打字 → 候选窗、浮窗照常出现（默认「自动」不应影响日常）
90. 打开一个独占全屏游戏（或按 `Alt+Enter` 切全屏）→ 在游戏里打字，**不弹候选窗**，
    候选以 `1.xx 2.xx` 的形式拼在组合串后面；`Alt+Tab` 切回桌面后立刻恢复候选窗
    （`Activate` 里会丢掉检测缓存，不用等 400ms）
91. 设置里改成「始终不弹」→ 桌面上的记事本里也不再弹候选窗，浮窗消失；
    按 `Ctrl+Shift+U` → 恢复；再按一次 → 又收起（这个键只影响当前窗口，不写配置）
92. 设置里改成「始终弹出」→ 全屏游戏里候选窗仍然弹（自动检测被手动档覆盖）
93. 升级安装：旧 `config.ini` 里是 `no_popup=0` → 打开设置看「候选窗」勾在**自动**；
    旧 `no_popup=1` → 勾在**始终不弹**（老配置语义不被改写）

**M3.17（多音字 + 常见词）**

94. 打 `tj`（tán）→ 候选里有「弹」（以前只有 `dj` 的 dàn 那边有）；敲 `tj` 后翻页不再是
    唯一办法；`tji` 出「弹出」、`tjil` 出「弹窗」
95. 打 `di`（dì）→ 候选里有「的」（多音字 `de/di` 两边都在）；`hang` 出「行」同理
96. 打「下拉框」「输入框」「任务管理器」「短视频」「优惠券」「周报」→ 整词直接出，
    不需要再造词；`src/extra_dict.txt` 里能看到这些词
97. 打一个词库里没有的新词（如 `nirandewangzhan` → 你然的网站）→ 仍走分词 + 自造词，
    第二个字翻页时**单字排在词前面**（码长短 = 更完整）

**M3.18（同码第二个自造词 / 左右键逐字选择）**

98. 造一个两音节以上的词（例：`limkyr` → 选「李」「明」「远」→ 上屏），再敲 `limkyr`
    → 候选第一位是「李明远」
99. 接着敲 `limkyr`，按一下 `←` → 组合串变成 `[李][明][远]`（三段，光标在第一段），
    **不会**因为整串有候选而进不去；按 `→` 可以逐段右移
100. 把最后一段用数字键换成「源」，空格确认到底 → 上屏「李明源」；再敲 `limkyr`
    → 候选依次是「李明源」「李明远」（新的在前，旧的没丢）
101. 单音节码（`de` / `ni`）里按 `←` `→` 仍是移动选中项，不会进逐字模式
102. 三音节以上的码按 `→` 后如果某段仍是两字词（如 `[李明]远`），在那段上按退格能拆成单字

**M3.19（分类词表：常用词 / 中药 / 药品 / 地名 / IT）**

103. 打「枸杞」「当归」「黄芪」→ 整词直出，且与词库里已有词不冲突（`tjil` 仍出「弹窗」）
104. 这几个多音/生僻字中药名按**正确读音**能敲出来：川芎（chuan xiong）、黄柏（huang bo）、
    枳壳（zhi qiao）、桑螵蛸（sang piao xiao）、荜澄茄（bi cheng qie）——拼音错一个就整词
    打不出来，对应 `tools/pinyin_overrides.txt` 里的校正
105. 打「六味地黄丸」「阿莫西林」「布洛芬」「对乙酰氨基酚」→ 整词直出
106. 打「乌鲁木齐」「蚌埠」「亳州」「番禺」→ 整词直出（地名古音按当地读法）
107. 打「并发」「熔断」「灰度」「幂等」「脱敏」→ IT 词整词直出
108. 打「外卖」「快递柜」「空调」「洗衣机」这类日常词 → 直出，不需要再造词
109. 词库里没有的词仍然走分词 + 自造词，不因为词库变大就退化成「只能整词查」

**M3.20（术数词表：六十甲子 / 六十四卦 / 神煞 / 奇门 / 大六壬 / 六爻）**

110. 打「甲子」「壬寅」「癸亥」→ 整词直出（六十甲子 60 条全收，顺序不影响输入）
111. 「水雷屯」按 **shuǐ léi zhūn**（「屯」读 zhūn）打才出；按 tún 打不出来是**对的**，
     卦名从来读 zhūn。同理「天地否」按 **pǐ**、「山火贲」按 **bì**、「雷水解」按 **xiè**
112. 「火雷噬嗑」按 shì hé 打（`huo lei shi he`）、「风天小畜」「山天大畜」按 **xù** 打；
     「小畜」「大畜」「噬嗑」这些两字简称同样能直出
113. 「乾为天」「天风姤」「泽天夬」「火泽睽」「水山蹇」→ 全名直出；
     「同人卦」「归妹卦」「既济卦」→ 「X卦」形式也直出
114. 神煞：「天乙贵人」「羊刃」「空亡」「华盖」「十恶大败」「黄道吉日」→ 整词直出
115. 奇门：「值符」「生门」「三奇得使」「玉女守门」「天网四张」「阳遁九局」→ 直出
116. 大六壬：「四课三传」「初传」「重审课」（zhòng，不是 chóng）「昴星课」「斫轮课」→ 直出
117. 六爻：「纳甲」「世爻」「用神」「月建」「日辰」「旺相休囚死」「揲蓍」（shé shī）→ 直出
