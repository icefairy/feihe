## 一、装完之后要做的两件事

1. **把飞鹤加进键盘列表**（只需要做一次）
   打开「设置 → 时间和语言 → 语言和区域 → 中文(简体，中国) → ⋯ → 语言选项 →
   添加键盘 → 飞鹤拼音」。
   如果列表里还没出现「飞鹤拼音」，**注销一次**——键盘列表由系统外壳缓存。
   安装本身**不需要重启电脑**，安装程序也不会要求；装完直接就能切过去用。

2. **切过去**
   按 `Win + 空格`（或 `Ctrl + Shift`）在输入法之间轮换，任务栏右下角会显示「中」。

> 安装时会弹一次 **UAC（用户账户控制）**，点「是」继续——注册输入法必须写系统级
> 注册表，普通权限做不到。
> 如果 Windows 还弹「已保护你的电脑」，点「更多信息 → 仍要运行」。
> 安装包没有买代码签名证书，这是正常的，不是文件损坏。

## 二、怎么打字

**飞鹤不是全拼，是小鹤双拼。** 每个音节固定两个键：**声母键 + 韵母键**。

```text
声母键位
  zh = v    ch = i    sh = u
  其余声母就用字母本身：b p m f d t n l g k h j q x r z c s y w

韵母键位
  Q iu    W ei    E e     R uan   T ue    Y un    U u/sh   I i/ch   O o/uo   P ie
  A a     S ong   D ai    F en    G eng   H ang   J an    K uai    L iang
  Z ou    X ia    C ao    V ui/zh B in    N iao   M ian
```

口诀：**秋闱软月云梳翅，松拥黛粉更航安，快莺两望奏夏蛙，撇草追鱼滨鸟眠。**

几个例子：

| 想打 | 全拼 | 双拼按键 |
|---|---|---|
| 你好 | ni hao | `nihc` |
| 中国 | zhong guo | `vsgo` |
| 世界 | shi jie | `uijp` |
| 按钮 | an niu | `annq` |
| 是 | shi | `ui` |

**零声母**（没有声母的音节）：

- 单字母韵母：**重复该字母**。啊 `aa`、哦 `oo`、额 `ee`
- 双字母韵母：**保持全拼**。爱 `ai`、安 `an`、欧 `ou`
- 三字母及以上：**用韵母所在的键**。昂 `ah`、鞥 `eg`

**打错了**：退格删一个键，`Esc` 整串取消。
（例外：整串的上屏结果已经是一个词时，退格改成「切开来逐字选」，见「长句」一节。）

**中英文切换**：**单击一下 Shift**（按住期间按过别的键就不算单击）。
**`Shift + 字母` 直接上屏大写字母**，不会进组合串；已经打了一半的编码会先按当前
候选上屏，再粘上这个大写字母。切到英文后所有按键原样进应用，候选窗不弹。

**每次打开输入法进中文还是英文，由你定。** 设置窗最上面有「启动默认」：中文（默认）
或英文，每次激活输入法（切窗口、开机）都回到这里选的模式。单击 Shift 切换的只影响
当前会话——关掉程序再开，回到的是「启动默认」，不是上次切到的状态。

### 一级简码：一个键一个字

26 个字母键各配一个「这个键底下最常用的字」。敲一个键，它就是第一候选，
空格直接上屏——不用翻、不用选：

```text
q 去   w 我   e 二   r 人   t 他   y 一   u 是   i 出   o 哦   p 平
a 啊   s 三   d 的   f 发   g 个   h 和   j 就   k 可   l 了
z 在   x 小   c 才   v 这   b 不   n 你   m 没
```

口诀：**去我二人他，一是出哦平；啊三的发个，和就可了；在小才这，不你没。**

几个看着奇怪的位置都有原因：`u` 在小鹤双拼里兼 `sh`，所以「是」在 `u`；
`v` 兼 `zh`，「这」在 `v`；`i` 兼 `ch`，「出」在 `i`。

两点要说明：

- **只对单键生效**。敲第二个键就回到正常排序（`d` 出「的」，`de` 按词频排）。
- **一简字排在动态调频前面**。不管你把「大」选过多少次，`d` 的第一个仍然是「的」——
  这是打字的肌肉记忆，不该被偶发的学习结果顶掉。真想让别的字排第一，用下面的**置顶**。

**每个键还有一个次选**，固定在第二位，按分号键可以直接取：

```text
q 期    w 位    e 嗯嗯   r 然后   t 提供   y 有时   u 时    i 重新   o 哦哦   p 便宜
a 安装  s 所有  d 打     f 复杂   g 管     h 忽略   j 见    k 可以   l 理解
z 自动  x 显示  c 词库   v 之     b 比较   n 内容   m 没有
```

比如敲 `d` 再敲 `;`，直接出「打」；不想记就正常按数字 `2`。
代价是原来的第二位被挤掉了（`d` 的第 2 位从「大」变成「打」）——这是小鹤的既定排法，
如果你更想要「大」，选中它按 `Ctrl`+数字 置顶即可。
分号只在「刚敲了一个字母」时才是次选键，其他时候仍然是断开音节的分隔符。

### 二级简码：两个键一个词

常用的两字词，各取两个字**双拼码的第一个键**，两个键就能出来：

```text
nd 难道   py 拼音   jd 简单   sy 所以   wm 我们   xz 现在
jj 解决   bt 不同   um 什么   vd 知道   ux 首先   zx 在线
```

共 370 个词（小鹤官方表，首选 273 + 次选 97）。

**有的词排在第二位**：两键码不够分，好码先给了单字。比如 `mm` 这个码本来归「面」，
所以「慢慢」排在第二位——打 `mm` 第一位是「面」，选第二个才是「慢慢」。`nd` 反过来，
「难道」在第一位，「奶」退到第二位。不想记这些细节也没关系：**看候选窗选就行**。

如果某个词抢了你常用的字，选中那个字按 `Ctrl`+数字 把它置顶，以后就反过来了。

### 想换掉一简字？用置顶

两个办法，效果一样：

- **`Ctrl` + 数字**：把候选**钉**到当前编码上并上屏，以后打这个码它永远第一。
  对已经置顶的那个词再按一次就是**取消置顶**。
- **鼠标右键点候选**：同样切换置顶，但**不会上屏**，打字不会被打断。

右键这条在浏览器、VS Code 这类多页签程序里特别有用——它们把 `Ctrl+1..9` 抢去切页签了，
输入法根本收不到。右击后候选会立刻重排：钉上的词跳到第一个，取消的回到原位。

> 全屏游戏（UILess 模式）时候选由游戏自己画，没有我们的候选窗，右键用不上。

| 例子 | 效果 |
|---|---|
| 打 `d`，按 `Ctrl+2` 选「大」 | 以后 `d` 第一个就是「大」，不再是「的」 |
| 打 `iuliqi`，按 `Ctrl+3` 选「处理器」 | 以后 `iuliqi` 直接出「处理器」 |
| 打 `d`，选中已经是置顶的「大」，`Ctrl+数字` | 取消置顶，`d` 回到「的」 |

置顶压过一简首选 / 次选、压过二简词、压过动态调频、压过词库词频。记录在
`<安装目录>\pinned.txt`（一行「编码<TAB>词」），可以手改、可以整个删掉；
设置窗里能看当前置顶并一键清空。

## 三、候选窗怎么操作

| 按键 | 作用 |
|---|---|
| `1` ~ `9` | 选第几个候选 |
| `空格` | 选第一个候选 |
| `回车` | 把敲的编码**原样上屏**（`iuliqi` → `iuliqi`，不选词） |
| `←` `→` | **切到逐字选择**（多音节码，见下一节）；单个音节的码里是左右移动选中项 |
| `-` `=` 或 `↑` `↓` | 上一页 / 下一页 |
| `Esc` | 取消，什么都不上屏 |
| `Ctrl` + `1`~`9` | 选第几个候选，**并把它置顶到这个编码**（再按一次取消） |
| **鼠标点击** | 直接点候选词就上屏；点了不会让输入框失焦 |

**候选不设上限**：这个词码下有多少条就出多少条，按 `+` / `-` 能一直翻到最后一个。
所以生僻字（比如 `ji` 里的「玑」）一定会出现，只是可能排在后面几页。
早期版本按码长砍过候选数（1 键 18 个、2 键 45 个、3 键 90 个），结果把后半截字
静默藏了起来——想打的字根本不在列表里，比「要翻很多页」严重得多。

**它绝不自动上屏。** 只有你按空格 / 数字 / 回车 / 标点，字才会写进文档。

### 快速找字：多行候选

一页只有 9 个，`ji` 这样的码有十几页，一个个翻很累。**按一次 `+`（或 `=`、`↓`），
候选窗会长高，一次摊开 5 行 45 个**：

```text
1.机 2.几 3.级 4.及 5.既 6.即 7.集 8.急 9.记
1.计 2.鸡 3.极 4.积 5.挤 6.季 7.寄 8.纪 9.击
1.己 2.济 3.辑 4.击 5.姬 6.讥 7.畸 8.稽 9.迹
1.缉 2.肌 3.饥 4.矶 5.戟 6.伎 7.妓 8.稷 9.鲫
1.绩 2.给 3.寂 4.脊 5.瘠 6.冀 7.嵇 8.畿 9.玑   ← 活动行（高亮在这，数字键选这行）
```

规则只有三条：

1. **数字键选的是「活动行」**——就是高亮那一行。
2. **每按一次 `+`，活动行往下走一行**：在第 3 行看到想要的字，按两次 `+` 让活动行
   落到那一行，再按它的数字。活动行走到最下面之后，整窗开始上滚——新的第 6 行从
   下面进来，第 1 行从上面出去。
3. **退回第 1 页再按 `-`，就收起成单行**（老样子）。

行数默认 5，在设置窗「翻页时显示行数」里改成 1~9；设成 1 就是单行。
展开只影响「一眼能看见多少」，数字键的语义和单行时完全一样，打出来的字不会变。

### 易错词的读音（打错读音也能出来）

有些词里的字是多音字，而词库每条只存一个读音。飞鹤对这些词做两件事：

```text
1.重庆 chóng qìng   2.弹窗 tán chuāng   3.你好   4.银行 yín háng
```

- **标读音**：易错词后面跟一串带调的拼音，小一号灰字，只在它们身上出现
- **按错读音也能打**：`重庆` 挂在 `chóng` 下，你按 `zhong qing` 打也能出来
  ——排在那个码正常候选的**最后面**（`zhongqing` 先是「钟情」，翻过去才是「重庆」）

哪些词算易错？读音和这个字的**默认读音**不一样的词，全库 4.6 万条里只有 753 个，
比如 `重庆` `弹窗` `川芎` `六安` `水雷屯`。普通词（`你好` `我们`）读音没歧义，
不标注，也不占地方。

不想要这串拼音：设置 → 「易错词标注读音」取消勾选。**错音容错不受影响**——
它只是多给一个候选，不多占一个像素。


### 长句：自动分词 + 逐段选

打一长串、整串又查不到词时（比如 `nihaoshijie`），飞鹤会把它切成几段挂起来：

```text
组合串显示：[你好]世界      ← [] 里是当前段
```

| 按键 | 作用 |
|---|---|
| `←` `→` | 移到上一段 / 下一段 |
| `1` ~ `9` | 给当前段换词（候选窗显示的是这一段的候选） |
| `空格` | 确认当前段并跳到下一段（最后一段则整体上屏） |
| `回车` | 原样上屏**字母**（`mmap` → `mmap`）。已经用空格/数字选过的段保留汉字 |
| **`退格`** | **拆开当前段（词 → 单字）**，拆不动了才退掉最后一个音节 |
| 继续敲字母 | 延长组合串并重新分段，已选过的段会保留 |

**回车永远是「我就要这些字母」。** 和没进分词模式时一个意思，不会因为碰巧能切成
音节就变成汉字——否则打 `mmap` 会出「面ap」。想把这一串中文上屏，就一路按空格
确认到底（最后一段会自动整体上屏）。

**退格拆词**是最有用的一把：自动分段只会挑「词库里能匹配上的最长词」，
比如 `limkyr` 会被切成 `[李明]远`。如果你要的是「李」+「明」+「远」，
按一次退格把 `李明` 拆成两个字，候选窗立刻变成「李」的字候选，选完自动跳到「明」。
**这一步不丢编码**，再按一次退格才真的删掉末尾音节。

**整串已经有候选时，按 `←`/`→` 也能进。** 自动分词只在「一个候选都没有」时触发，
但左右键是手动入口：敲完 `limkyr`（已经学会「李明远」）按一下 `←`，编码就切成
`[李][明][远]`，每段都能用数字换成别的字。单音节的码（`de`、`ni`）切不出第二段，
左右键在那里还是移动选中项。

**退格也能直接进。** 判据是「整串的上屏结果是个词」：打 `zuci` 出来「组词」，
想再造一个「祖祠」，按一下**退格**，编码不删，直接切成 `[组][词]`，从第一个字开始
重选即可。`xrji`（璇玑）、`limkyr`（李明远）同理，哪怕这些码已经有别的候选也一样。

第一候选是**单字**（`de` → 的）或者还没打出候选时，退格仍然是删字母——那是改错最
常用的场景，不能劫持。要删字母又已经在逐字模式里，按 `Esc` 退出重打即可。

**翻页选字**：分段后每一段都有自己的候选页，`+` / `-`（或 `↑` / `↓`）翻页，数字键取的是
**当前页**的那一个。比如 `fwhe` 拆成 `[飞][鹤]`，「鹤」在第二页第三位，翻过去按 `3`
上屏的就是「鹤」。

**翻页时候选窗会摊开成多行**（默认 5 行 = 45 个，见「快速找字：多行候选」），
翻页一次只挪一行，数字键选的是高亮的「活动行」。

### 自造词：拼出来的新词会记住

上面那条路能让你打出词库里**没有**的词（人名、公司名、专有词），但麻烦在于：
拼一次只顶一次用，下次敲同样的码又得从头拆一遍、选一遍。飞鹤会把你这次
**一个段一个段拼出来**的词记下来，下次同样的码打满就直接给：

```text
第一次：limkyr → 退格拆词 → 选「李」「明」「远」 → 上屏「李明远」
之后：  limkyr → 候选第一位就是「李明远」
```

几条规矩（都是为了不乱记）：

- 只在**分词模式**里记（组合串显示成 `[李明]远` 那种），而且至少两段
- **自动分词、你没动过就上屏**的词不记——词库里本来就有，记了只是重复
- 存的是**全拼**，所以换双拼方案、切全拼模式之后照样打得出来
- 关掉设置里的「**动态调频**」就不再记新词（已有记录不清空）
- 记录在 `%LOCALAPPDATA%\Feihe\phrases.txt`，删掉文件即全部忘掉；
  设置窗的「动态调频」那一栏能看到已记多少个自造词，也能一键清空

**同一个码可以挂多个词。** 已经学会「李明远」之后，还想用 `limkyr` 造同音的「李明源」：
敲 `limkyr` → 按 `←` 进逐字模式 → 数字键把最后一个字选成「源」→ 空格确认到底。
新学会的排候选第一位，旧的退到第二位，两个都在。
**整串上屏结果是个词时**（第一候选是两字以上的词），按一下退格就能进逐字模式，
不需要方向键；第一候选是单字或者还没出候选时，退格还是删字母，那就用 `←`。

### 手动分隔

自动切分还是不理想时，可以用 `'` 强制断一刀：

- 全拼 / 小鹤双拼：`;`（如 `xi'an`）
- 微软双拼：`'`（分号被 `ing` 占了）

分隔符只帮你切，**不会进文档**。

## 四、辅助码：给「音」再加一道「形」

音码打完之后，候选里还剩一堆同音字。`ji` 底下有 128 个单字，第一位是「机」，
可你要的是「记」——那就得翻好几页。

**辅助码就是这时候再加一道筛子**：音码打完，接着把字的「形状」用一两个字母输进去，
候选立刻从几十个缩到一两个。它不改变你怎么打字，只是让你少翻页。

设置窗「辅助码」里三选一（**新装默认是「自然码辅助码」**）：

| 方案 | 键数 | 取码规则 |
|---|---|---|
| 关闭 | 0 | `Tab` 还给应用（在编辑器里就是缩进），不拦 |
| 自然码辅助码（默认） | 1 键 | 部首读音首字母：`的`→白→`b`、`打`→扌(手)→`s` |
| 小鹤音形 | 2 键 | 首部件 + 末部件，官方码：`打`→扌+丁→`fd`、`带`→带上+巾→`fj` |

**两套和输入模式互不干扰**：小鹤双拼配自然码辅助码、微软双拼配小鹤音形，都可以。
全拼模式下也能用（先按 `Tab` 再敲形码；只是「连打再按 `Tab`」那招不成立，因为全拼的
码长不固定，挪不出末尾哪几个键是形码）。

### 怎么用：三步

```text
ji                音码
ji → Tab          组合串末尾多出一个空格位，等着填形码
ji → Tab → m j    组合串显示成「ji mj」，候选只剩木字旁的字，「机」在第一位
```

敲完按空格就是「机」。组合串里那个空格只是分隔标记，**不会进文档**。

| 按键 | 作用 |
|---|---|
| `Tab` | 进入辅助码筛选；再按一次退出（形码清空，候选恢复原样） |
| 形码字母 | 缩小候选。自然码 1 键、小鹤 2 键 |
| `退格` | 删一个形码字母；删空就自动退出辅助码态 |
| `-` `=` / `↑` `↓` | 翻页（和平时一样） |
| `空格` / 数字 | 上屏 |
| `Esc` | 整个取消 |

**先连打、再按 `Tab` 也认**：小鹤把两键一次敲完（`dd` + `f` + `j`）再按 `Tab`，末尾能
当形码用的键会自动挪进辅助码，组合串直接变成 `dd fj`，不用退格重来。自然码同理，
只是只挪末尾 1 键。

### 小鹤音形（2 键）

规则：**首部件的声母 + 末部件的声母**。字根划分和码表用的是小鹤官方那一套，和
`react.xhup.club` 反查出来的码逐字一致——那里查到的码，这里可以直接用。

| 字 | 拆法 | 形码 |
|---|---|---|
| 打 | 扌(f) + 丁(d) | `fd` |
| 带 | 带字头(f) + 巾(j) | `fj` |
| 机 | 木(m) + 几(j) | `mj` |
| 记 | 讠(y) + 己(j) | `yj` |
| 计 | 讠(y) + 十(u) | `yu` |
| 玑 | 王(w) + 几(j) | `wj` |

有些字看不出规律，那是官方给「独体字 / 特殊字根」单独定的码，照抄就行，别硬猜：
`简` 是 `vo`、`明` 是 `oo`、`及` 是 `pn`。记不住就用 `/fc` 反查（见「快捷输入」）。

**例 1：同音字太多**

```text
ji → Tab → m j      →  机      （木 + 几）
ji → Tab → y u      →  计      （讠 + 十）
ji → Tab → y j      →  记      （讠 + 己）
ji → Tab → w j      →  玑      （王 + 几，平时排在很后面）
```

只敲第一键 `y` 的时候「计 / 记」都还在（都是言字旁），是第二键把两者分开的——
这正是 2 键比 1 键强的地方。

**例 2：给词定位**

词的辅助码只按**首字**算，所以它管的是「这一批同音字里，要哪个字开头的词」：

```text
dd → Tab → f        →  「带」开头的词（带上、带来、带进）
dd → Tab → r y      →  「代」开头的词（代表）
```

`dd` 底下有「大 / 代 / 待 / 带 / 戴 / 呆 / 贷」一串同音字，按 `f` 就只剩「带」那一支。

**例 3：形码打满，单字自动置顶**

小鹤形码打满 2 键后，形码和输入**完全相等**的单字会被顶到第一位，哪怕它不如同码的
词常用：

```text
jm → Tab → v o      →  简      （「简单」更常用，但打满了就该给这个字）
```

### 自然码辅助码（1 键）

规则：**取部首的读音首字母**。只有一键，所以它把同音字按「什么旁」分成二十来类。

| 字 | 部首 | 辅助码 |
|---|---|---|
| 的 | 白(bái) | `b` |
| 打 | 扌(手 shǒu) | `s` |
| 想 | 心(xīn) | `x` |
| 你 | 亻(人 rén) | `r` |
| 机 | 木(mù) | `m` |
| 简 | 竹(zhú) | `z` |
| 大 | 大(dà) | `d` |

**例 1：一个字一个键**

```text
da → Tab → s          →  打      （扌）
da → Tab → d          →  大      （大）
```

**例 2：同音字多的时候，一键就把它们切开**

`dd`（dai）底下这几个字，每个落在不同的键上：

```text
代 → r（人）    待 → c（彳，读 chì）   戴 → g（戈）
呆 → k（口）    贷 → b（贝）           带 → j（巾）
```

所以 `dd → Tab → j` 直接是「带」开头的词，不夹杂「代表 / 待机」。

**例 3：1 键也算「打满」**

自然码只取一键，所以按完这一键就算形码打满，**形码完全相等的单字同样会被顶到第一
位**：

```text
ji → Tab → m          →  机      （木）排在第一位，不用翻
```

**一键的天然极限**：同一部首的字分不开——`计` 和 `记` 的自然码都是 `y`（讠），
按完还得看候选。想分开就得多一个键，也就是下面这套。

### 两套怎么选

| | 自然码辅助码 | 小鹤音形 |
|---|---|---|
| 键数 | 1 | 2 |
| 怎么记 | 念一遍部首名（白、手、心、人） | 记小鹤官方字根（一百多个） |
| 区分力 | 同部首的字仍然重码 | 首末两道，重码很少 |
| 适合 | 偶尔用、不想背字根 | 天天用、想要「打满就出那一个字」 |
| 同音对比 | `计` / `记` 都是 `y` | `计`=`yu`、`记`=`yj` |

随时能换：设置里选完立刻生效，已经打了一半的码接着敲就行。

### 五条容易踩的

1. **筛选是过滤，不是排序。** 形码筛不到就是**一条候选都没有**，翻多少页都找不到
   ——形码写错不会「排到后面」，而是直接空窗。这时按 `Tab` 退出，或退格删掉形码。
2. **键数有上限**：自然码 1 键、小鹤 2 键。多敲一个字母 = 筛空。
3. **辅助码态里进不了分词。** 想逐段改长句，先按 `Tab` 退出。
4. **词只按首字筛。** 第二个字的形状不参与，所以给词加形码不会「越筛越准」；
   想让词更准，把音码打全，让整串本身就是个词。
5. **表里查不到的字没有辅助码**（少数生僻字），按了 `Tab` 之后它会被筛掉。

### 和「3 键直出」的关系

设置里那个「**3 键直出单字**」（默认关）就是省掉 `Tab`：第 3 键直接当形码。

```text
自然码：da + s            →  打      （不用按 Tab）
小鹤：  dd + f            →  带      （第 3 键先当第一道形码）
        接着再敲 j        →  dd fj   →  带
```

它是在猜，猜错会自动退回：继续打下去如果整串本身是个词（`ykwf` → 英文），就并回音码
出词；筛空了也会并回。**自己按 `Tab` 拆的辅助码不会被自动撤销**——那是明确意图，
要退出就再按一次 `Tab`。

## 五、快捷输入（先敲 `/`）

按 `/`（问号那个键），后面接命令码。**只打首字母也行**：
`/r` 就等于 `/rq`。只打一个 `/` 会列出所有命令的预览，用数字挑。

| 输入 | 得到 |
|---|---|
| `/rq` | `2026年10月23日` / `2026-10-23` / `2026/10/23` / `2026.10.23` / `10月23日` / `23日` |
| `/sj` | `17:40` / `17:40:06` / `下午5点40分` / `下午5:40` |
| `/xq` | `星期四` / `周四` |
| `/dt` | `2026-10-23 17:40:06` / `… 17:40` / `2026年10月23日 17:40` / `… 星期四` |
| `/ts` | Unix 秒 / Unix 毫秒 |
| `/nl` | 农历：`农历丙午年九月十四` / `丙午年九月十四` / `九月十四` |
| `/gz` | 干支四柱：`丙午年 戊戌月 庚午日 壬午时` / `丙午 戊戌 庚午 壬午` / 不带时的三柱 |
| `/jq` | 下一个节气：`2026年11月7日 立冬` / `11月7日 立冬` / `立冬` |
| `/fc` | 反查剪贴板里的汉字：`璇 xuan+wr  玑 ji+wj` / `璇玑  xrji → wr` |

### `/fc` 反查：这个字该怎么打

复制一个打不出来的字或词，敲 `/fc`：

- **第一条候选**是逐字明细：`字 全拼+形码`，例如 `璇 xuan+wr  玑 ji+wj`。
- **第二条候选**是能直接照着敲的连打串：`璇玑  xrji → wr`——先敲 `xrji`，按 `Tab`，
  再敲 `wr`。单字时这一条就是完整的码（`玑` → `jiwj`）。

形码跟着设置里的辅助码方案走（自然码 1 键 / 小鹤音形 2 键），音码跟着输入模式走
（双拼模式给双拼码 `xr`，全拼模式给 `xuan`）。读音取自本输入法自己的词库，所以
给出来的码一定能敲出来。

### 农历 / 干支 / 节气说明

- **`/nl` 农历**：按农历年输出干支年（**按春节换年**）。闰月会写成「闰六月」。
- **`/gz` 干支**：这是**四柱（八字）**，不是农历年。年柱**按立春换**、月柱**按节气换**、
  日柱**按子时（23:00）换日**。所以春节前后几天、立春前后几天，`/nl` 和 `/gz` 的
  年份会不一样——这是对的，两者本来就是两套历法。
- **`/jq` 节气**：给你**最近的下一个**节气，精确到日。如果今天正好是节气当天，
  给的就是今天这个。

> 农历 / 干支 / 节气的计算统一来自 [Tyme](https://6tail.cn/tyme.html)（MIT 许可），
> 节气算法引自寿星天文历。三个功能共用同一套儒略日，不会互相打架。

> 为什么引导符是 `/`：顿号只留 `\` 一个键（搜狗习惯）就够了，`/` 位置好记好按，
> 拿来当功能入口更划算。中间一度搬到反引号，但那个键太偏、记不住，又换回来了。
>
> 代价是中文态下 `/` 不再出顿号。**想打斜杠**：敲 `/` 再按空格或回车——
> 只打了引导符本身时，第一候选就是 `/` 本身（全角模式是 `／`），命令预览排在后面。
>
> **已经打了一半编码时按 `/`**：会先把你当前选的候选上屏，再输出斜杠
> （`de` + `/` → `的/`）。以前这个键会被直接吞掉，斜杠凭空消失。

## 六、状态浮窗与设置

屏幕右下角有一条小横条（可以拖动，位置会记住；也可以让它跟随光标）：

| 按钮 | 作用 |
|---|---|
| 中 / 英 | 切换中英文 |
| 全 / 半 | 全角符号宽度：开着时英文态下的标点用全角形式（，．；，占一个汉字宽）。中文态恒为中文标点 |
| 符号 | 打开符号软键盘（9×5 网格，点击即插入） |
| 设置 | 打开设置窗口 |

设置窗口的**标题栏带版本号**（`飞鹤输入法 · 设置 · 0.3.8`），反馈问题时截个图就能
知道是哪一版，不用去翻安装包。

设置窗口里能改：

- **输入模式**：双拼 / 全拼
- **启动默认**：中文 / 英文——每次激活输入法（切窗口、开机）进入的模式（默认中文）。
  单击 Shift 切换只影响当前会话
- **双拼方案**：小鹤 / 微软
- **辅助码**：关闭 / 自然码（默认）/ 小鹤音形——打完码按 `Tab` 再加一道「形」的筛选，
  详见「辅助码」一章
  - 为什么必须按 `Tab`：`ddj` 也是「代价 / 待机 / 带进」这些词的合法前缀，
    键盘分不清你要的是「带 + 部首 j」还是「带 + 价没打完」，所以得给一个明确的进入信号
  - **3 键直出单字**（默认关）：打开后第 3 键直接当形码，`ddj` 不按 `Tab` 就出「带」。
    它是在猜，猜错会自动并回音码；用户自己 `Tab` 拆的不在此列
  - 官方反查工具的码（`react.xhup.club`）和这里完全是同一套；懒得查工具就复制那个字，
    敲 `/fc`
- **皮肤**：浅色 / 深色 / 护眼
- **字形**：简体 / 繁体
- **全角符号**（默认开）：只管标点**宽度**。中文态恒出中文标点；英文态标点默认
  半角，开了全角换成全角英文标点（，．；［］……占一个汉字宽，和中文标点是不同的
  字符）。字母、数字不受影响
- **浮窗跟随光标**
- **候选窗何时收起**：自动（默认）/ 始终弹出 / 始终不弹（见下）
- **动态调频**（按你实际选词调整候选顺序）+ **自造词**（自动记住你拼出来的新词）+ **重置**
- **置顶**：看当前置顶了哪些码 + 一键清空
- **词库**：统计、导入、导出、编译个人词库

窗口最下面是「**关于**」：一段项目自述和仓库地址
`https://github.com/icefairy/feihe`。点那行地址或旁边的「打开项目主页」，会用你的
默认浏览器打开 GitHub 页面（输入法自己不联网，只是把地址交给系统）。

### 全屏游戏：UILess（候选交给游戏自己画）

独占全屏的游戏会绕开 Windows 的桌面合成器（DWM），输入法自己开的窗口**画了也不上屏**。
这类游戏如果按 TSF 的 **UILess** 方式启动（主流引擎都做了：LOL、原神、魔兽世界、CS2…），
TSF 会告诉飞鹤「别自己画，把候选数据交给我」。飞鹤实现了这条通道，于是：

- 候选框由**游戏**画在它的界面里，和它自己的 UI 一个字体、一个风格；
- 数字键选词、`-` `=` 翻页、方向键移动，和桌面上手感一致；
- **自动生效，没有开关**——游戏要，飞鹤就给。

打不出候选的话，先确认游戏是不是「独占全屏」。改成**无边框窗口 / 窗口化**一定可用
（那时它就是个普通窗口）。

### 候选窗什么时候收起：全屏自动检测

**默认全自动，不用改设置。** 打字的瞬间飞鹤会问一下 Windows「现在是不是全屏」，是就
**一个窗口都不弹**——没有候选窗，也没有右下角那条浮窗。这时候它只依赖输入框自己的组合串
（那是应用画在界面里的，不是我们弹的窗口），候选改写成纯文本跟在编码后面：

```text
nihc  1.你好 2.拟好 3.你号 …
```

数字键照样选，`-` `=` 照样翻页，空格出第一候选。没有候选窗可点，所以**鼠标选词在这个状态下不可用**。

会触发的三种情况（设置里选「自动」时）：

- 独占全屏的 D3D 程序（游戏）
- 演示 / 投影模式（别人的屏幕上不该冒出候选窗）
- 全屏的 UWP 应用（商店版游戏、视频 App）

**手动档**在设置里「候选窗」那一行，三选一：

- **自动**（默认）：按上面的规则检测
- **始终弹出**：自动检测误判成「全屏」时用（比如无边框窗口跑游戏，候选窗其实能显示）
- **始终不弹**：远程桌面、虚拟机控制台，或者自动检测认不出来的独占全屏程序

**临时切换**：`Ctrl+Shift+U` 按一次切到相反状态，再按一次回到「跟随设置」。它**不写配置**，
只管当前这个窗口——是应急键，不是设置项。浮窗被藏起来时，这也是唯一能回到设置窗的入口
（没有浮窗就没有「设置」按钮）。

（万一真锁住了：把 `%LOCALAPPDATA%\Feihe\config.ini` 里的 `popup=` 改成 `auto`。）

> **做不到的**：如果某个程序既不走 UILess、也不显示组合串（极少数完全自绘输入框的
> 引擎），飞鹤在里面一个字也打不出来。那种场景只剩「键盘钩子 + 模拟按键 + 注入进程
> 画候选」的外挂式工具，飞鹤不做：这类工具要常驻监听全部按键、往游戏进程里塞代码，
> 反作弊会直接判成外挂，风险和维护成本都远超收益。

## 七、词库

内置 4.7 万条词、8006 个单字（《通用规范汉字表》可编码的全收，再补 GB2312 独有的字）。
词库分 13 份：基础词库 + 手工补充表，外加 12 份自动生成的分类词表——日常常用词、
IT 行业词、地名、通用药品名、中药名、中成药名，以及术数类的六十甲子、六十四卦、
神煞名、奇门遁甲、大六壬、六爻。
够日常，但**不是「什么都有」**——专业术语、网络新词、人名地名基本查不到，可以自己补：

1. **导入搜狗个人词库**：设置窗 → 「导入词库…」，选搜狗用户目录里的词库文件；
   也可以手工准备一个「每行 `词<TAB>全拼`」的文本再导入。
2. **编译个人词库**：导入后会自动编译；手改过文本的话点一下「编译个人词库」。
   二进制版本走内存映射，多个程序共用一份，更省内存也更快。
   它编译的是你的 `user_dict.txt`，不是程序本身。还没导入过个人词库时那个文件不存在，
   点了只会提示「还没有个人词库」，不是出错。
3. **动态调频**：你选了哪个词，下次它就往前排——只在**同样键数**的候选之间调，
   所以敲 `ig` 第一位永远还是「成」，不会因为你常打「程序」就被顶掉。
   不想要就在设置里关掉，或点「重置」。
4. **自造词**：词库里没有的词，你用分词模式一段一段拼出来的，飞鹤会自动记住，
   下次同样的码打满就直接出（存的是全拼，换方案也不丢）。想忘掉就点「重置」。

用户词库的源文件在 `%LOCALAPPDATA%\Feihe\user_dict.txt`，可以手工编辑、可以导出。

## 八、标点与符号

**用哪套标点跟中英切换走**：中文态下不带 Shift 的标点键输出中文标点（恒定，
与全角开关无关）；英文态标点原样进应用（半角），全角开关开着时换成全角英文标点。

| 键 | 中文态输出 | 英文态（全角开） |
|---|---|---|
| `,` `.` | `，` `。` | `，` `．` |
| `;` `'` | `；` `’` | `；` `＇` |
| `[` `]` | `【` `】` | `［` `］` |
| `\` | `、`（顿号只留这一个键） | `＼` |
| `-` `=` `/` | `－` `＝` `／` | `－` `＝` `／` |
| `Shift + \` | `\|`（交给应用自己出） | 同左 |

> `:` `?` `!` 这类需要按 Shift 的符号一律由应用自己出（键盘布局决定，输入法不猜），
> 中文态也不例外——想要「：」「？」用中文标点软键盘或直接打中文。

组合串还没上屏时按标点键，会先把候选上屏、紧跟着粘上标点，
**不会**出现「，,」两个字符。

## 九、常见问题

**装了但输入法列表里没有「飞鹤拼音」**
键盘列表由外壳缓存，注销一次或重启。仍然没有的话，用管理员权限重跑一遍安装包。

**首次运行被 SmartScreen 拦住**
安装包没有代码签名。点「更多信息 → 仍要运行」。

**更新版本后还是旧行为**
覆盖安装完成后，点一下任意输入框即可——安装时已经重启过输入法进程，新 DLL 会在下次
输入时自动加载，不用注销也不用重启。

**候选窗位置不对 / 不跟着光标走**
设置里关掉「浮窗跟随光标」试试；某些全屏程序或游戏里候选窗位置由宿主决定。
如果候选窗干脆看不见、或者一弹出来就把游戏切到窗口模式，把「候选窗」改成 **始终不弹**。

**在游戏里完全打不出字**
先看游戏是全屏还是窗口化。独占全屏下，游戏得按 TSF 的 UILess 方式启动、候选才会由
游戏自己画出来（主流游戏都支持，飞鹤也实现了这条通道）；不支持就切**无边框窗口**，
那时它是个普通窗口，一切正常。还不行就把「候选窗」改成 **始终不弹**，候选会变成纯文本跟在编码后面。
见「全屏游戏：UILess」和「候选窗什么时候收起」两节。

**改了双拼方案，别的程序没立刻变**
已经打开的进程要重新激活一次（点一下那个窗口）才读到新配置，不用重启。

**安装目录里有一堆 `feihe.dll.old-*`**
覆盖安装时旧 DLL 常被输入法进程占着，只能改名等重启删。现在安装结束时会自动重启输入法
进程（ctfmon），残留的 `.old` 文件会被顺手清掉；万一有漏网的，重启后可手动删除，
不影响使用。

**想彻底卸载**
「设置 → 应用 → 已安装的应用 → 飞鹤拼音 → 卸载」，或运行安装目录里的 `uninstall.exe`。
卸载会清掉 COM / TSF 注册和安装目录，但**不会删你的个人数据**（见下）。

## 十、数据与隐私

- **不联网**。程序里没有任何网络代码（连导入表里都没有 `wininet` / `winhttp` / `ws2_32`），
  不是「承诺不上传」，是「没写这个功能」。
- **不要账号**，没有广告，没有热点推送。
- **密码框里一个字都不接管**：登录框、支付密码、Wi-Fi 密码这类输入位置，输入法
  不弹候选、不组组合串、不把字母变成汉字，按键原样进应用。判据是 TSF 的
  `IS_PASSWORD` 输入范围，加上经典编辑框的 `ES_PASSWORD` 样式位（两套都要，
  老程序不设前者）。单击 Shift 切中英在密码框里照常可用。
- 你的数据全在**安装目录**（默认 `%LOCALAPPDATA%\Feihe\`）下：

| 文件 | 内容 |
|---|---|
| `config.ini` | 设置项 |
| `freq.txt` | 动态调频的学习记录（纯文本 `码<TAB>词<TAB>次数`，删掉即重置） |
| `phrases.txt` | 自造词（纯文本 `词<TAB>全拼<TAB>次数`，删掉即全部忘掉） |
| `pinned.txt` | 手动置顶（纯文本 `编码<TAB>词`，删掉即全部取消） |
| `user_dict.txt` | 你的个人词库（源文件，可编辑） |
| `user.bin` | 上面那个文件编译出来的二进制 |

**备份 = 压缩这个文件夹。** 所有数据都和程序放在一起，所以拷走安装目录（或者直接压成
zip）就是一份完整备份：换机、重装、给第二台电脑用，解压回去就能接着用，设置和打字的
习惯都跟着走。恢复时先退掉输入法（切到英文键盘即可）再覆盖文件，否则可能被占用。

卸载不会动这个目录（数据文件留在原处，目录因而不会被删）。想彻底清干净，卸载后手动删除整个安装目录即可。

> 装到只读位置（比如手动装进 `C:\Program Files`）时，程序写不进去会自动把数据放到
> `%APPDATA%\Feihe`，设置窗底部的「数据目录」会显示**实际在用**的那个路径——以它为准。

## 十二、输入法不见了怎么办

装完更新后，如果语言列表（Win+空格）里看不到「飞鹤拼音」，「添加键盘」里也没有，
或者设置里出现一个灰色的「不可用的输入法」——**不用重装**：打开安装目录，
**右键 `Feihe-Repair.exe` → 以管理员身份运行**。

它会先检查一遍注册状态，再决定要不要动手：

- **一切正常**：直接弹「当前注册状态正常，不需要修复」，**一个字都不写**。这时候如果
  你在 Win+空格里还是看不到它，多半是列表缓存没刷新——注销后重登一次即可。
- **有缺项**：窗口里会列出缺了什么（`[need]` 开头的那几行），然后重新注册 COM / TSF
  组件和键盘列表，几秒钟完成，最后弹「修复完成」。

修复过程**不改动任何文件**，不会动你的词库、自造词和个人设置，也不影响正在运行的程序
——浏览器、微信开着也能修，不用关掉重开。

> 必须用管理员身份运行：注册信息写在系统的机器级注册表里（`HKLM`），普通权限写不进去。
> 以前版本写在用户级注册表里，看起来能装好，但系统的输入法列表根本读不到——这就是
> 「多出一个不可用的输入法、却切不到飞鹤」的原因。

修完用 Win+空格或 Ctrl+Shift 切换；如果列表里还是看不到，注销后重新登录一次
（语言列表由 shell 缓存，注销最快）。

找不到安装目录时：控制面板「程序和功能」里找到「飞鹤拼音」，右键属性里「位置」那一栏
就是；默认是 `%LOCALAPPDATA%\Feihe`。
