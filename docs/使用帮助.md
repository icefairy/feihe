## 一、装完之后要做的两件事

1. **把飞鹤加进键盘列表**（只需要做一次）
   打开「设置 → 时间和语言 → 语言和区域 → 中文(简体，中国) → ⋯ → 语言选项 →
   添加键盘 → 飞鹤拼音」。
   如果列表里还没出现「飞鹤拼音」，**注销一次或重启**——键盘列表由系统外壳缓存。

2. **切过去**
   按 `Win + 空格`（或 `Ctrl + Shift`）在输入法之间轮换，任务栏右下角会显示「中」。

> 装的时候如果 Windows 弹「已保护你的电脑」，点「更多信息 → 仍要运行」。
> 安装包没有买代码签名证书，这是正常的，不是文件损坏。

## 二、怎么打字

**飞鹤不是全拼，是小鹤双拼。** 每个音节固定两个键：**声母键 + 韵母键**。

```text
声母键位
  zh = v    ch = i    sh = u
  其余声母就用字母本身：b p m f d t n l g k h j q x r z c s y w

韵母键位
  Q iu    W ei    E e     R uan   T ue    Y un    U u/sh   I i/ch   O o/uo   P ie
  A a     S ong   D ai    F en    G eng   H ang   J an    K uai    L iang
  Z ou    X ia    C ao    V ui/zh B in    N iao   M ian
```

口诀：**秋闱软月云梳翅，松拥黛粉更航安，快莺两望奏夏蛙，撇草追鱼滨鸟眠。**

几个例子：

| 想打 | 全拼 | 双拼按键 |
|---|---|---|
| 你好 | ni hao | `nihc` |
| 中国 | zhong guo | `vsgo` |
| 世界 | shi jie | `uijp` |
| 按钮 | an niu | `annq` |
| 是 | shi | `ui` |

**零声母**（没有声母的音节）：

- 单字母韵母：**重复该字母**。啊 `aa`、哦 `oo`、额 `ee`
- 双字母韵母：**保持全拼**。爱 `ai`、安 `an`、欧 `ou`
- 三字母及以上：**用韵母所在的键**。昂 `ah`、鞥 `eg`

**打错了**：退格删一个键，`Esc` 整串取消。

**中英文切换**：**单击一下 Shift**（按住期间按过别的键就不算单击）。
**`Shift + 字母` 直接上屏大写字母**，不会进组合串；已经打了一半的编码会先按当前
候选上屏，再粘上这个大写字母。切到英文后所有按键原样进应用，候选窗不弹。

### 一级简码：一个键一个字

26 个字母键各配一个「这个键底下最常用的字」。敲一个键，它就是第一候选，
空格直接上屏——不用翻、不用选：

```text
q 去   w 我   e 二   r 人   t 他   y 一   u 是   i 出   o 哦   p 平
a 啊   s 三   d 的   f 发   g 个   h 和   j 就   k 可   l 了
z 在   x 小   c 才   v 这   b 不   n 你   m 没
```

口诀：**去我二人他，一是出哦平；啊三的发个，和就可了；在小才这，不你没。**

几个看着奇怪的位置都有原因：`u` 在小鹤双拼里兼 `sh`，所以「是」在 `u`；
`v` 兼 `zh`，「这」在 `v`；`i` 兼 `ch`，「出」在 `i`。

两点要说明：

- **只对单键生效**。敲第二个键就回到正常排序（`d` 出「的」，`de` 按词频排）。
- **一简字排在动态调频前面**。不管你把「大」选过多少次，`d` 的第一个仍然是「的」——
  这是打字的肌肉记忆，不该被偶发的学习结果顶掉。真想让别的字排第一，用下面的**置顶**。

**每个键还有一个次选**，固定在第二位，按分号键可以直接取：

```text
q 期    w 位    e 嗯嗯   r 然后   t 提供   y 有时   u 时    i 重新   o 哦哦   p 便宜
a 安装  s 所有  d 打     f 复杂   g 管     h 忽略   j 见    k 可以   l 理解
z 自动  x 显示  c 词库   v 之     b 比较   n 内容   m 没有
```

比如敲 `d` 再敲 `;`，直接出「打」；不想记就正常按数字 `2`。
代价是原来的第二位被挤掉了（`d` 的第 2 位从「大」变成「打」）——这是小鹤的既定排法，
如果你更想要「大」，选中它按 `Ctrl`+数字 置顶即可。
分号只在「刚敲了一个字母」时才是次选键，其他时候仍然是断开音节的分隔符。

### 二级简码：两个键一个词

常用的两字词，各取两个字**双拼码的第一个键**，两个键就能出来：

```text
nd 难道   py 拼音   jd 简单   sy 所以   wm 我们   xz 现在
jj 解决   bt 不同   um 什么   vd 知道   ux 首先   zx 在线
```

共 370 个词（小鹤官方表，首选 273 + 次选 97）。

**有的词排在第二位**：两键码不够分，好码先给了单字。比如 `mm` 这个码本来归「面」，
所以「慢慢」排在第二位——打 `mm` 第一位是「面」，选第二个才是「慢慢」。`nd` 反过来，
「难道」在第一位，「奶」退到第二位。不想记这些细节也没关系：**看候选窗选就行**。

如果某个词抢了你常用的字，选中那个字按 `Ctrl`+数字 把它置顶，以后就反过来了。

### 想换掉一简字？用置顶

两个办法，效果一样：

- **`Ctrl` + 数字**：把候选**钉**到当前编码上并上屏，以后打这个码它永远第一。
  对已经置顶的那个词再按一次就是**取消置顶**。
- **鼠标右键点候选**：同样切换置顶，但**不会上屏**，打字不会被打断。

右键这条在浏览器、VS Code 这类多页签程序里特别有用——它们把 `Ctrl+1..9` 抢去切页签了，
输入法根本收不到。右击后候选会立刻重排：钉上的词跳到第一个，取消的回到原位。

> 全屏游戏（UILess 模式）时候选由游戏自己画，没有我们的候选窗，右键用不上。

| 例子 | 效果 |
|---|---|
| 打 `d`，按 `Ctrl+2` 选「大」 | 以后 `d` 第一个就是「大」，不再是「的」 |
| 打 `iuliqi`，按 `Ctrl+3` 选「处理器」 | 以后 `iuliqi` 直接出「处理器」 |
| 打 `d`，选中已经是置顶的「大」，`Ctrl+数字` | 取消置顶，`d` 回到「的」 |

置顶压过一简首选 / 次选、压过二简词、压过动态调频、压过词库词频。记录在
`%APPDATA%\Feihe\pinned.txt`（一行「编码<TAB>词」），可以手改、可以整个删掉；
设置窗里能看当前置顶并一键清空。

## 三、候选窗怎么操作

| 按键 | 作用 |
|---|---|
| `1` ~ `9` | 选第几个候选 |
| `空格` | 选第一个候选 |
| `回车` | 把敲的编码**原样上屏**（`iuliqi` → `iuliqi`，不选词） |
| `←` `→` | **切到逐字选择**（多音节码，见下一节）；单个音节的码里是左右移动选中项 |
| `-` `=` 或 `↑` `↓` | 上一页 / 下一页 |
| `Esc` | 取消，什么都不上屏 |
| `Ctrl` + `1`~`9` | 选第几个候选，**并把它置顶到这个编码**（再按一次取消） |
| **鼠标点击** | 直接点候选词就上屏；点了不会让输入框失焦 |

**候选数量按码长自动收敛**：打一个键给 18 个（2 页），两个键给 45 个（5 页），
三个键以上才给满 90 个。第一个键不会甩给你十页生僻字。

**它绝不自动上屏。** 只有你按空格 / 数字 / 回车 / 标点，字才会写进文档。

### 易错词的读音（打错读音也能出来）

有些词里的字是多音字，而词库每条只存一个读音。飞鹤对这些词做两件事：

```text
1.重庆 chóng qìng   2.弹窗 tán chuāng   3.你好   4.银行 yín háng
```

- **标读音**：易错词后面跟一串带调的拼音，小一号灰字，只在它们身上出现
- **按错读音也能打**：`重庆` 挂在 `chóng` 下，你按 `zhong qing` 打也能出来
  ——排在那个码正常候选的**最后面**（`zhongqing` 先是「钟情」，翻过去才是「重庆」）

哪些词算易错？读音和这个字的**默认读音**不一样的词，全库 4.6 万条里只有 753 个，
比如 `重庆` `弹窗` `川芎` `六安` `水雷屯`。普通词（`你好` `我们`）读音没歧义，
不标注，也不占地方。

不想要这串拼音：设置 → 「易错词标注读音」取消勾选。**错音容错不受影响**——
它只是多给一个候选，不多占一个像素。


### 长句：自动分词 + 逐段选

打一长串、整串又查不到词时（比如 `nihaoshijie`），飞鹤会把它切成几段挂起来：

```text
组合串显示：[你好]世界      ← [] 里是当前段
```

| 按键 | 作用 |
|---|---|
| `←` `→` | 移到上一段 / 下一段 |
| `1` ~ `9` | 给当前段换词（候选窗显示的是这一段的候选） |
| `空格` | 确认当前段并跳到下一段（最后一段则整体上屏） |
| `回车` | 原样上屏**字母**（`mmap` → `mmap`）。已经用空格/数字选过的段保留汉字 |
| **`退格`** | **拆开当前段（词 → 单字）**，拆不动了才退掉最后一个音节 |
| 继续敲字母 | 延长组合串并重新分段，已选过的段会保留 |

**回车永远是「我就要这些字母」。** 和没进分词模式时一个意思，不会因为碰巧能切成
音节就变成汉字——否则打 `mmap` 会出「面ap」。想把这一串中文上屏，就一路按空格
确认到底（最后一段会自动整体上屏）。

**退格拆词**是最有用的一把：自动分段只会挑「词库里能匹配上的最长词」，
比如 `limkyr` 会被切成 `[李明]远`。如果你要的是「李」+「明」+「远」，
按一次退格把 `李明` 拆成两个字，候选窗立刻变成「李」的字候选，选完自动跳到「明」。
**这一步不丢编码**，再按一次退格才真的删掉末尾音节。

**整串已经有候选时，按 `←`/`→` 也能进。** 自动分词只在「一个候选都没有」时触发，
但左右键是手动入口：敲完 `limkyr`（已经学会「李明远」）按一下 `←`，编码就切成
`[李][明][远]`，每段都能用数字换成别的字。单音节的码（`de`、`ni`）切不出第二段，
左右键在那里还是移动选中项。

**整串只有一个候选时，退格也能进。** 打 `zuci` 出来唯一的「组词」，想再造一个
「祖祠」：按一下**退格**，编码不删，直接切成 `[组][词]`，从第一个字开始重选即可。
候选有两个以上时退格照旧删字母——那里退格的主要用途还是改错。

**翻页选字**：分段后每一段都有自己的候选页，`+` / `-`（或 `↑` / `↓`）翻页，数字键取的是
**当前页**的那一个。比如 `fwhe` 拆成 `[飞][鹤]`，「鹤」在第二页第三位，翻过去按 `3`
上屏的就是「鹤」。

### 自造词：拼出来的新词会记住

上面那条路能让你打出词库里**没有**的词（人名、公司名、专有词），但麻烦在于：
拼一次只顶一次用，下次敲同样的码又得从头拆一遍、选一遍。飞鹤会把你这次
**一个段一个段拼出来**的词记下来，下次同样的码打满就直接给：

```text
第一次：limkyr → 退格拆词 → 选「李」「明」「远」 → 上屏「李明远」
之后：  limkyr → 候选第一位就是「李明远」
```

几条规矩（都是为了不乱记）：

- 只在**分词模式**里记（组合串显示成 `[李明]远` 那种），而且至少两段
- **自动分词、你没动过就上屏**的词不记——词库里本来就有，记了只是重复
- 存的是**全拼**，所以换双拼方案、切全拼模式之后照样打得出来
- 关掉设置里的「**动态调频**」就不再记新词（已有记录不清空）
- 记录在 `%APPDATA%\Feihe\phrases.txt`，删掉文件即全部忘掉；
  设置窗的「动态调频」那一栏能看到已记多少个自造词，也能一键清空

**同一个码可以挂多个词。** 已经学会「李明远」之后，还想用 `limkyr` 造同音的「李明源」：
敲 `limkyr` → 按 `←` 进逐字模式 → 数字键把最后一个字选成「源」→ 空格确认到底。
新学会的排候选第一位，旧的退到第二位，两个都在。
**整串只有一个候选时**，按一下退格就能进逐字模式（不需要方向键）；候选多的时候
退格还是删字母，那就用 `←`。

### 手动分隔

自动切分还是不理想时，可以用 `'` 强制断一刀：

- 全拼 / 小鹤双拼：`;`（如 `xi'an`）
- 微软双拼：`'`（分号被 `ing` 占了）

分隔符只帮你切，**不会进文档**。

## 四、快捷输入（先敲 `/`）

按 `/`（问号那个键），后面接命令码。**只打首字母也行**：
`/r` 就等于 `/rq`。只打一个 `/` 会列出所有命令的当前值，用数字挑。

| 输入 | 得到 |
|---|---|
| `/rq` | `2026年10月23日` / `2026-10-23` / `2026/10/23` / `2026.10.23` / `10月23日` / `23日` |
| `/sj` | `17:40` / `17:40:06` / `下午5点40分` / `下午5:40` |
| `/xq` | `星期四` / `周四` |
| `/dt` | `2026-10-23 17:40:06` / `… 17:40` / `2026年10月23日 17:40` / `… 星期四` |
| `/ts` | Unix 秒 / Unix 毫秒 |
| `/nl` | 农历：`农历丙午年九月十四` / `丙午年九月十四` / `九月十四` |
| `/gz` | 干支四柱：`丙午年 戊戌月 庚午日 壬午时` / `丙午 戊戌 庚午 壬午` / 不带时的三柱 |
| `/jq` | 下一个节气：`2026年11月7日 立冬` / `11月7日 立冬` / `立冬` |

### 农历 / 干支 / 节气说明

- **`/nl` 农历**：按农历年输出干支年（**按春节换年**）。闰月会写成「闰六月」。
- **`/gz` 干支**：这是**四柱（八字）**，不是农历年。年柱**按立春换**、月柱**按节气换**、
  日柱**按子时（23:00）换日**。所以春节前后几天、立春前后几天，`/nl` 和 `/gz` 的
  年份会不一样——这是对的，两者本来就是两套历法。
- **`/jq` 节气**：给你**最近的下一个**节气，精确到日。如果今天正好是节气当天，
  给的就是今天这个。

> 农历 / 干支 / 节气的计算统一来自 [Tyme](https://6tail.cn/tyme.html)（MIT 许可），
> 节气算法引自寿星天文历。三个功能共用同一套儒略日，不会互相打架。

> 为什么引导符是 `/`：顿号只留 `\` 一个键（搜狗习惯）就够了，`/` 位置好记好按，
> 拿来当功能入口更划算。中间一度搬到反引号，但那个键太偏、记不住，又换回来了。
>
> 代价是中文态下 `/` 不再出顿号。想打半角斜杠：敲 `/` 再按**回车**——
> 只敲了引导符本身时，回车会把它原样上屏（`/` 或全角的 `／`）。

## 五、状态浮窗与设置

屏幕右下角有一条小横条（可以拖动，位置会记住；也可以让它跟随光标）：

| 按钮 | 作用 |
|---|---|
| 中 / 英 | 切换中英文 |
| 全 / 半 | 切换全角 / 半角标点 |
| 符号 | 打开符号软键盘（9×5 网格，点击即插入） |
| 设置 | 打开设置窗口 |

设置窗口里能改：

- **输入模式**：双拼 / 全拼
- **双拼方案**：小鹤 / 微软
- **辅助码**：关闭 / 自然码 / 小鹤音形（`Tab` 进入辅助码筛选，再按 `Tab` 退出）
  - 自然码：1 键，取部首读音首字母，如 的→白→`b`、带→巾→`j`
  - 小鹤音形：2 键，取首末部件，**用官方码**，如 带→`fj`（带上是 f、巾是 j）、打→`fd`
  - 打法：打 `dd` → `Tab` → `f` → `j`，第一位就是「带」；先连打也行，`ddfj` → `Tab`
    会把末尾的 `fj` 自动挪成辅助码，组合串显示成 `dd fj`
  - 为什么必须按 `Tab`：`ddj` 也是「代价 / 待机 / 带进」这些词的合法前缀，
    键盘分不清你要的是「带 + 部首 j」还是「带 + 价没打完」，所以得给一个明确的进入信号
  - 官方反查工具的码（`react.xhup.club`）和设置里这套是完全一致的
- **皮肤**：浅色 / 深色 / 护眼
- **字形**：简体 / 繁体
- **全角标点**（默认开）
- **浮窗跟随光标**
- **候选窗何时收起**：自动（默认）/ 始终弹出 / 始终不弹（见下）
- **动态调频**（按你实际选词调整候选顺序）+ **自造词**（自动记住你拼出来的新词）+ **重置**
- **置顶**：看当前置顶了哪些码 + 一键清空
- **词库**：统计、导入、导出、编译个人词库

### 全屏游戏：UILess（候选交给游戏自己画）

独占全屏的游戏会绕开 Windows 的桌面合成器（DWM），输入法自己开的窗口**画了也不上屏**。
这类游戏如果按 TSF 的 **UILess** 方式启动（主流引擎都做了：LOL、原神、魔兽世界、CS2…），
TSF 会告诉飞鹤「别自己画，把候选数据交给我」。飞鹤实现了这条通道，于是：

- 候选框由**游戏**画在它的界面里，和它自己的 UI 一个字体、一个风格；
- 数字键选词、`-` `=` 翻页、方向键移动，和桌面上手感一致；
- **自动生效，没有开关**——游戏要，飞鹤就给。

打不出候选的话，先确认游戏是不是「独占全屏」。改成**无边框窗口 / 窗口化**一定可用
（那时它就是个普通窗口）。

### 候选窗什么时候收起：全屏自动检测

**默认全自动，不用改设置。** 打字的瞬间飞鹤会问一下 Windows「现在是不是全屏」，是就
**一个窗口都不弹**——没有候选窗，也没有右下角那条浮窗。这时候它只依赖输入框自己的组合串
（那是应用画在界面里的，不是我们弹的窗口），候选改写成纯文本跟在编码后面：

```text
nihc  1.你好 2.拟好 3.你号 …
```

数字键照样选，`-` `=` 照样翻页，空格出第一候选。没有候选窗可点，所以**鼠标选词在这个状态下不可用**。

会触发的三种情况（设置里选「自动」时）：

- 独占全屏的 D3D 程序（游戏）
- 演示 / 投影模式（别人的屏幕上不该冒出候选窗）
- 全屏的 UWP 应用（商店版游戏、视频 App）

**手动档**在设置里「候选窗」那一行，三选一：

- **自动**（默认）：按上面的规则检测
- **始终弹出**：自动检测误判成「全屏」时用（比如无边框窗口跑游戏，候选窗其实能显示）
- **始终不弹**：远程桌面、虚拟机控制台，或者自动检测认不出来的独占全屏程序

**临时切换**：`Ctrl+Shift+U` 按一次切到相反状态，再按一次回到「跟随设置」。它**不写配置**，
只管当前这个窗口——是应急键，不是设置项。浮窗被藏起来时，这也是唯一能回到设置窗的入口
（没有浮窗就没有「设置」按钮）。

（万一真锁住了：把 `%APPDATA%\Feihe\config.ini` 里的 `popup=` 改成 `auto`。）

> **做不到的**：如果某个程序既不走 UILess、也不显示组合串（极少数完全自绘输入框的
> 引擎），飞鹤在里面一个字也打不出来。那种场景只剩「键盘钩子 + 模拟按键 + 注入进程
> 画候选」的外挂式工具，飞鹤不做：这类工具要常驻监听全部按键、往游戏进程里塞代码，
> 反作弊会直接判成外挂，风险和维护成本都远超收益。

## 六、词库

内置 4.7 万条词、8006 个单字（《通用规范汉字表》可编码的全收，再补 GB2312 独有的字）。
词库分 13 份：基础词库 + 手工补充表，外加 12 份自动生成的分类词表——日常常用词、
IT 行业词、地名、通用药品名、中药名、中成药名，以及术数类的六十甲子、六十四卦、
神煞名、奇门遁甲、大六壬、六爻。
够日常，但**不是「什么都有」**——专业术语、网络新词、人名地名基本查不到，可以自己补：

1. **导入搜狗个人词库**：设置窗 → 「导入词库…」，选搜狗用户目录里的词库文件；
   也可以手工准备一个「每行 `词<TAB>全拼`」的文本再导入。
2. **编译个人词库**：导入后会自动编译；手改过文本的话点一下「编译个人词库」。
   二进制版本走内存映射，多个程序共用一份，更省内存也更快。
   它编译的是你的 `user_dict.txt`，不是程序本身。还没导入过个人词库时那个文件不存在，
   点了只会提示「还没有个人词库」，不是出错。
3. **动态调频**：你选了哪个词，下次它就往前排——只在**同样键数**的候选之间调，
   所以敲 `ig` 第一位永远还是「成」，不会因为你常打「程序」就被顶掉。
   不想要就在设置里关掉，或点「重置」。
4. **自造词**：词库里没有的词，你用分词模式一段一段拼出来的，飞鹤会自动记住，
   下次同样的码打满就直接出（存的是全拼，换方案也不丢）。想忘掉就点「重置」。

用户词库的源文件在 `%APPDATA%\Feihe\user_dict.txt`，可以手工编辑、可以导出。

## 七、标点与符号

中文模式下，不带 Shift 的那一排标点键输出全角标点。

| 键 | 输出 |
|---|---|
| `,` `.` `;` `:` `?` `!` | `，` `。` `；` `：` `？` `！` |
| `(` `)` `[` `]` | `（` `）` `【` `】` |
| `\` | `、`（顿号只留这一个键） |
| `Shift + \` | `\|`（交给应用自己出） |
| `/` | 不是标点，是快捷输入的引导符 |

组合串还没上屏时按标点键，会先把候选上屏、紧跟着粘上全角标点，
**不会**出现「，,」两个字符。

## 八、常见问题

**装了但输入法列表里没有「飞鹤拼音」**
键盘列表由外壳缓存，注销一次或重启。仍然没有的话，用管理员权限重跑一遍安装包。

**首次运行被 SmartScreen 拦住**
安装包没有代码签名。点「更多信息 → 仍要运行」。

**更新版本后还是旧行为**
覆盖安装完成后，点一下任意输入框即可——安装时已经重启过输入法进程，新 DLL 会在下次
输入时自动加载，不用注销也不用重启。

**候选窗位置不对 / 不跟着光标走**
设置里关掉「浮窗跟随光标」试试；某些全屏程序或游戏里候选窗位置由宿主决定。
如果候选窗干脆看不见、或者一弹出来就把游戏切到窗口模式，把「候选窗」改成 **始终不弹**。

**在游戏里完全打不出字**
先看游戏是全屏还是窗口化。独占全屏下，游戏得按 TSF 的 UILess 方式启动、候选才会由
游戏自己画出来（主流游戏都支持，飞鹤也实现了这条通道）；不支持就切**无边框窗口**，
那时它是个普通窗口，一切正常。还不行就把「候选窗」改成 **始终不弹**，候选会变成纯文本跟在编码后面。
见「全屏游戏：UILess」和「候选窗什么时候收起」两节。

**改了双拼方案，别的程序没立刻变**
已经打开的进程要重新激活一次（点一下那个窗口）才读到新配置，不用重启。

**安装目录里有一堆 `feihe.dll.old-*`**
覆盖安装时旧 DLL 常被输入法进程占着，只能改名等重启删。现在安装结束时会自动重启输入法
进程（ctfmon），残留的 `.old` 文件会被顺手清掉；万一有漏网的，重启后可手动删除，
不影响使用。

**想彻底卸载**
「设置 → 应用 → 已安装的应用 → 飞鹤拼音 → 卸载」，或运行安装目录里的 `uninstall.exe`。
卸载会清掉 COM / TSF 注册和安装目录，但**不会删你的个人数据**（见下）。

## 九、数据与隐私

- **不联网**。程序里没有任何网络代码（连导入表里都没有 `wininet` / `winhttp` / `ws2_32`），
  不是「承诺不上传」，是「没写这个功能」。
- **不要账号**，没有广告，没有热点推送。
- 你的数据全在 `%APPDATA%\Feihe\` 下：

| 文件 | 内容 |
|---|---|
| `config.ini` | 设置项 |
| `freq.txt` | 动态调频的学习记录（纯文本 `词<TAB>次数`，删掉即重置） |
| `phrases.txt` | 自造词（纯文本 `词<TAB>全拼`，删掉即全部忘掉） |
| `pinned.txt` | 手动置顶（纯文本 `编码<TAB>词`，删掉即全部取消） |
| `user_dict.txt` | 你的个人词库（源文件，可编辑） |
| `user.bin` | 上面那个文件编译出来的二进制 |

卸载不会动这个目录。想彻底清干净，卸载后手动删除 `%APPDATA%\Feihe` 即可。
