## 一、装完之后要做的两件事

1. **把飞鹤加进键盘列表**（只需要做一次）
   打开「设置 → 时间和语言 → 语言和区域 → 中文(简体，中国) → ⋯ → 语言选项 →
   添加键盘 → 飞鹤拼音」。
   如果列表里还没出现「飞鹤拼音」，**注销一次**——键盘列表由系统外壳缓存。
   安装本身**不需要重启电脑**，安装程序也不会要求；装完直接就能切过去用。

2. **切过去**
   按 `Win + 空格`（或 `Ctrl + Shift`）在输入法之间轮换，任务栏右下角会显示「中」。

> 安装时会弹一次 **UAC（用户账户控制）**，点「是」继续——注册输入法必须写系统级
> 注册表，普通权限做不到。
> 如果 Windows 还弹「已保护你的电脑」，点「更多信息 → 仍要运行」。
> 安装包没有买代码签名证书，这是正常的，不是文件损坏。

## 二、怎么打字

**飞鹤不是全拼，是小鹤双拼。** 每个音节固定两个键：**声母键 + 韵母键**。

```text
声母键位
  zh = v    ch = i    sh = u
  其余声母就用字母本身：b p m f d t n l g k h j q x r z c s y w

韵母键位
  Q iu    W ei    E e     R uan   T ue    Y un    U u/sh   I i/ch   O o/uo   P ie
  A a     S ong   D ai    F en    G eng   H ang   J an    K uai    L iang
  Z ou    X ia    C ao    V ui/zh B in    N iao   M ian
```

口诀：**秋闱软月云梳翅，松拥黛粉更航安，快莺两望奏夏蛙，撇草追鱼滨鸟眠。**

几个例子：

| 想打 | 全拼 | 双拼按键 |
|---|---|---|
| 你好 | ni hao | `nihc` |
| 中国 | zhong guo | `vsgo` |
| 世界 | shi jie | `uijp` |
| 按钮 | an niu | `annq` |
| 是 | shi | `ui` |

**零声母**（没有声母的音节）：

- 单字母韵母：**重复该字母**。啊 `aa`、哦 `oo`、额 `ee`
- 双字母韵母：**保持全拼**。爱 `ai`、安 `an`、欧 `ou`
- 三字母及以上：**用韵母所在的键**。昂 `ah`、鞥 `eg`

**打错了**：退格删一个键，`Esc` 整串取消。
（例外：整串的上屏结果已经是一个词时，退格改成「切开来逐字选」，见「长句」一节。）

**中英文切换**：**单击一下 Shift**（按住期间按过别的键就不算单击）。
**`Shift + 字母` 直接上屏大写字母**，不会进组合串；已经打了一半的编码会先按当前
候选上屏，再粘上这个大写字母。切到英文后所有按键原样进应用，候选窗不弹。

**每次打开输入法进中文还是英文，由你定。** 设置窗最上面有「启动默认」：中文（默认）
或英文，每次激活输入法（切窗口、开机）都回到这里选的模式。单击 Shift 切换的只影响
当前会话——关掉程序再开，回到的是「启动默认」，不是上次切到的状态。

### 一级简码：一个键一个字

26 个字母键各配一个「这个键底下最常用的字」。敲一个键，它就是第一候选，
空格直接上屏——不用翻、不用选：

```text
q 去   w 我   e 二   r 人   t 他   y 一   u 是   i 出   o 哦   p 平
a 啊   s 三   d 的   f 发   g 个   h 和   j 就   k 可   l 了
z 在   x 小   c 才   v 这   b 不   n 你   m 没
```

口诀：**去我二人他，一是出哦平；啊三的发个，和就可了；在小才这，不你没。**

几个看着奇怪的位置都有原因：`u` 在小鹤双拼里兼 `sh`，所以「是」在 `u`；
`v` 兼 `zh`，「这」在 `v`；`i` 兼 `ch`，「出」在 `i`。

两点要说明：

- **只对单键生效**。敲第二个键就回到正常排序（`d` 出「的」，`de` 按词频排）。
- **一简字排在动态调频前面**。不管你把「大」选过多少次，`d` 的第一个仍然是「的」——
  这是打字的肌肉记忆，不该被偶发的学习结果顶掉。真想让别的字排第一，用下面的**置顶**。

**每个键还有一个次选**，固定在第二位，按分号键可以直接取：

```text
q 期    w 位    e 嗯嗯   r 然后   t 提供   y 有时   u 时    i 重新   o 哦哦   p 便宜
a 安装  s 所有  d 打     f 复杂   g 管     h 忽略   j 见    k 可以   l 理解
z 自动  x 显示  c 词库   v 之     b 比较   n 内容   m 没有
```

比如敲 `d` 再敲 `;`，直接出「打」；不想记就正常按数字 `2`。
代价是原来的第二位被挤掉了（`d` 的第 2 位从「大」变成「打」）——这是小鹤的既定排法，
如果你更想要「大」，选中它按 `Ctrl`+数字 置顶即可。
分号只在「刚敲了一个字母」时才是次选键，其他时候仍然是断开音节的分隔符。

### 想换掉一简字？用置顶

两个办法，效果一样：

- **`Ctrl` + 数字**：把候选**钉**到当前编码上并上屏，以后打这个码它永远第一。
  对已经置顶的那个词再按一次就是**取消置顶**。
- **鼠标右键点候选**：同样切换置顶，但**不会上屏**，打字不会被打断。

右键这条在浏览器、VS Code 这类多页签程序里特别有用——它们把 `Ctrl+1..9` 抢去切页签了，
输入法根本收不到。右击后候选会立刻重排：钉上的词跳到第一个，取消的回到原位。

> 全屏游戏（UILess 模式）时候选由游戏自己画，没有我们的候选窗，右键用不上。

| 例子 | 效果 |
|---|---|
| 打 `d`，按 `Ctrl+2` 选「大」 | 以后 `d` 第一个就是「大」，不再是「的」 |
| 打 `iuliqi`，按 `Ctrl+3` 选「处理器」 | 以后 `iuliqi` 直接出「处理器」 |
| 打 `d`，选中已经是置顶的「大」，`Ctrl+数字` | 取消置顶，`d` 回到「的」 |

置顶压过一简首选 / 次选、压过二简词、压过动态调频、压过词库词频。记录在
`<安装目录>\pinned.txt`（一行「编码<TAB>词」），可以手改、可以整个删掉；
设置窗里能看当前置顶并一键清空。

### 想按下一个词？用降权

置顶是「拉一个上来」，降权是「按一个下去」。有些词只要误选一次就会长期压着你真正
想要的候选：打 `de` 时你不用的那个词老在第二三位，打 `shi` 时第一页塞满了陌生的词。
这时候别指望「多选几次把别的顶上来」——那得把每个词都选一遍。

- **`Ctrl` + 左键点候选**：这个词在当前编码下沉到**最后**（不删，翻页还能翻到）。
- 再 `Ctrl` + 左键点一次同一个词：**恢复**。

左键是选词、右键是置顶，两个都占了，所以降权用 `Ctrl`+左键。它**不占任何快捷键**，
不会和别的软件抢键。

| 例子 | 效果 |
|---|---|
| 打 `de`，`Ctrl`+左键点第二位的「得」 | 「得」沉到最后，`de` 的第一页干净了 |
| 再 `Ctrl`+左键点一次「得」 | 恢复原位 |

降权只压「默认排序」，压不过显式提权：一简字、二简词、自定义短语、手动置顶都还能把
它拽回前面。记录在 `<安装目录>\demoted.txt`（一行「编码<TAB>词」，一个码下可以按下去
好几个词），可以手改、可以整个删掉；设置窗里能看条数并一键清空。

## 三、候选窗怎么操作

| 按键 | 作用 |
|---|---|
| `1` ~ `9` | 选第几个候选 |
| `空格` | 选第一个候选 |
| `回车` | 把敲的编码**原样上屏**（`iuliqi` → `iuliqi`，不选词） |
| `←` `→` | **切到逐字选择**（多音节码，见下一节）；单个音节的码里是左右移动选中项 |
| `-` `=` 或 `↑` `↓` | 上一页 / 下一页 |
| `Esc` | 取消，什么都不上屏 |
| `Ctrl` + `1`~`9` | 选第几个候选，**并把它置顶到这个编码**（再按一次取消） |
| **鼠标点击** | 直接点候选词就上屏；点了不会让输入框失焦 |
| **鼠标右键** | 切换这个候选的置顶，**不上屏** |
| **`Ctrl` + 鼠标左键** | 切换这个候选的降权（沉到最后，不上屏） |

**候选不设上限**：这个词码下有多少条就出多少条，按 `+` / `-` 能一直翻到最后一个。
所以生僻字（比如 `ji` 里的「玑」）一定会出现，只是可能排在后面几页。
早期版本按码长砍过候选数（1 键 18 个、2 键 45 个、3 键 90 个），结果把后半截字
静默藏了起来——想打的字根本不在列表里，比「要翻很多页」严重得多。

**但「不设上限」说的是同一个码下有多少条，不是「任意长的词都列」。** 词的码长最多
比你已经敲的**多一个音节**（双拼 2 键、全拼 4 个字母）：

- 打 `wfjm`（wen jian，两个音节）→ 出现两字词和三字词（文件、文件名、文件夹），
  四字词「文件预览」不出现；
- 接着打 `wfjmyu`（三个音节）→ 「文件预览」出现，空格就上屏。

为什么留一个音节的余量：完全不留（码打满才出长词）会在打长词的中途出现**空候选窗**
（`wfjmyul` 时既没有 7 键的词、长词又被藏起来），看起来像输入法卡住了；留一个音节
既能让你提前看见快到手的长词，又不会被一堆四字词淹掉。

**它绝不自动上屏。** 只有你按空格 / 数字 / 回车 / 标点，字才会写进文档。

### 快速找字：多行候选

一页只有 9 个，`ji` 这样的码有十几页，一个个翻很累。**按一次 `+`（或 `=`、`↓`），
候选窗会长高，一次摊开 5 行 45 个**：

```text
1.机 2.几 3.级 4.及 5.既 6.即 7.集 8.急 9.记
1.计 2.鸡 3.极 4.积 5.挤 6.季 7.寄 8.纪 9.击
1.己 2.济 3.辑 4.击 5.姬 6.讥 7.畸 8.稽 9.迹
1.缉 2.肌 3.饥 4.矶 5.戟 6.伎 7.妓 8.稷 9.鲫
1.绩 2.给 3.寂 4.脊 5.瘠 6.冀 7.嵇 8.畿 9.玑   ← 活动行（高亮在这，数字键选这行）
```

规则只有三条：

1. **数字键选的是「活动行」**——就是高亮那一行。
2. **每按一次 `+`，活动行往下走一行**：在第 3 行看到想要的字，按两次 `+` 让活动行
   落到那一行，再按它的数字。活动行走到最下面之后，整窗开始上滚——新的第 6 行从
   下面进来，第 1 行从上面出去。
3. **退回第 1 页再按 `-`，就收起成单行**（老样子）。

行数默认 5，在设置窗「翻页时显示行数」里改成 1~9；设成 1 就是单行。
展开只影响「一眼能看见多少」，数字键的语义和单行时完全一样，打出来的字不会变。

### 易错词的读音（打错读音也能出来）

有些词里的字是多音字，而词库每条只存一个读音。飞鹤对这些词做两件事：

```text
1.重庆 chóng qìng   2.弹窗 tán chuāng   3.你好   4.银行 yín háng
```

- **标读音**：易错词后面跟一串带调的拼音，小一号灰字，只在它们身上出现
- **按错读音也能打**：`重庆` 挂在 `chóng` 下，你按 `zhong qing` 打也能出来
  ——排在那个码正常候选的**最后面**（`zhongqing` 先是「钟情」，翻过去才是「重庆」）

哪些词算易错？读音和这个字的**默认读音**不一样的词，全库 4.6 万条里只有 753 个，
比如 `重庆` `弹窗` `川芎` `六安` `水雷屯`。普通词（`你好` `我们`）读音没歧义，
不标注，也不占地方。

不想要这串拼音：设置 → 「易错词标注读音」取消勾选。**错音容错不受影响**——
它只是多给一个候选，不多占一个像素。


### 长句：自动分词 + 逐段选

打一长串、整串又查不到词时（比如 `nihaoshijie`），飞鹤会把它切成几段挂起来：

```text
组合串显示：[你好]世界      ← [] 里是当前段
```

| 按键 | 作用 |
|---|---|
| `←` `→` | 移到上一段 / 下一段 |
| `1` ~ `9` | 给当前段换词（候选窗显示的是这一段的候选） |
| `空格` | 确认当前段并跳到下一段（最后一段则整体上屏） |
| `回车` | 原样上屏**字母**（`mmap` → `mmap`）。已经用空格/数字选过的段保留汉字 |
| **`退格`** | **拆开当前段（词 → 单字）**，拆不动了才退掉最后一个音节 |
| 继续敲字母 | 延长组合串并重新分段，已选过的段会保留 |

**回车永远是「我就要这些字母」。** 和没进分词模式时一个意思，不会因为碰巧能切成
音节就变成汉字——否则打 `mmap` 会出「面ap」。想把这一串中文上屏，就一路按空格
确认到底（最后一段会自动整体上屏）。

**退格拆词**是最有用的一把：自动分段只会挑「词库里能匹配上的最长词」，
比如 `limkyr` 会被切成 `[李明]远`。如果你要的是「李」+「明」+「远」，
按一次退格把 `李明` 拆成两个字，候选窗立刻变成「李」的字候选，选完自动跳到「明」。
**这一步不丢编码**，再按一次退格才真的删掉末尾音节。

**整串已经有候选时，按 `←`/`→` 也能进。** 自动分词只在「一个候选都没有」时触发，
但左右键是手动入口：敲完 `limkyr`（已经学会「李明远」）按一下 `←`，编码就切成
`[李][明][远]`，每段都能用数字换成别的字。单音节的码（`de`、`ni`）切不出第二段，
左右键在那里还是移动选中项。

**退格也能直接进。** 判据是「整串的上屏结果是个词」：打 `zuci` 出来「组词」，
想再造一个「祖祠」，按一下**退格**，编码不删，直接切成 `[组][词]`，从第一个字开始
重选即可。`xrji`（璇玑）、`limkyr`（李明远）同理，哪怕这些码已经有别的候选也一样。

第一候选是**单字**（`de` → 的）或者还没打出候选时，退格仍然是删字母——那是改错最
常用的场景，不能劫持。要删字母又已经在逐字模式里，按 `Esc` 退出重打即可。

**翻页选字**：分段后每一段都有自己的候选页，`+` / `-`（或 `↑` / `↓`）翻页，数字键取的是
**当前页**的那一个。比如 `fwhe` 拆成 `[飞][鹤]`，「鹤」在第二页第三位，翻过去按 `3`
上屏的就是「鹤」。

**翻页时候选窗会摊开成多行**（默认 5 行 = 45 个，见「快速找字：多行候选」），
翻页一次只挪一行，数字键选的是高亮的「活动行」。

### 打错了：一键猜回来

按错一个键，整串就成了「每个字都认得、凑一起没这个词」。这种时候飞鹤会试着
**把某一个键换掉**，看能不能凑出词来：

```text
nihx  →  你好 / 你还 / 你和 / 你很 / 你换 / …        （x 按成了 c）
```

顺序是**最后按的键先试**——打错的多半是刚按下去那一下。同一串同一个错法，每次给
的候选顺序都一样，选过一次之后它会排到前面。

规则和边界：

- **只在一条候选都没有时才猜**。正常查得到词的时候，纠错完全不出场。
- **自动分词优先**。整串没词但能逐字组出来（「安并」这种人名式组合）时，还是老规矩
  切成段逐字选，不会先塞一屏纠错候选。
- **只换一个键**，不删不加。双拼每个音节恰好两键，删一个或加一个会让后面所有音节
  错位，猜中的概率比不猜还低。
- **至少两个音节**（4 键）。单个音节没词的情况太少，猜出来的一屏全是噪音。
- 猜错了就照常处理：**退格**删掉最后一个键重打，或者按 `←`/`→` 强制进分词逐字选。

### 自造词：拼出来的新词会记住

上面那条路能让你打出词库里**没有**的词（人名、公司名、专有词），但麻烦在于：
拼一次只顶一次用，下次敲同样的码又得从头拆一遍、选一遍。飞鹤会把你这次
**一个段一个段拼出来**的词记下来，下次同样的码打满就直接给：

```text
第一次：limkyr → 退格拆词 → 选「李」「明」「远」 → 上屏「李明远」
之后：  limkyr → 候选第一位就是「李明远」
```

几条规矩（都是为了不乱记）：

- 只在**分词模式**里记（组合串显示成 `[李明]远` 那种），而且至少两段
- **自动分词、你没动过就上屏**的词不记——词库里本来就有，记了只是重复
- 存的是**全拼**，所以换双拼方案、切全拼模式之后照样打得出来
- 关掉设置里的「**动态调频**」就不再记新词（已有记录不清空）
- 记录在 `%LOCALAPPDATA%\Feihe\phrases.txt`，删掉文件即全部忘掉；
  设置窗的「动态调频」那一栏能看到已记多少个自造词，也能一键清空

**同一个码可以挂多个词。** 已经学会「李明远」之后，还想用 `limkyr` 造同音的「李明源」：
敲 `limkyr` → 按 `←` 进逐字模式 → 数字键把最后一个字选成「源」→ 空格确认到底。
新学会的排候选第一位，旧的退到第二位，两个都在。

**自造词不是永远第一。** 它和词库里的候选用同一套「你选过几次」来排：造词时记一次，
之后每从候选里选一次再加一次。所以同一个码下，如果你后来反复选的是另一个词，
它会让位给那个词；反过来，刚造的词你一次都没选过，而对手是 0 次，它仍然排第一。
（这条以前是「自造词无条件排第一」，导致 `zirjma` 下早前自动学的「自然吗」永远
压着反复选过的「自然码」。）
**整串上屏结果是个词时**（第一候选是两字以上的词），按一下退格就能进逐字模式，
不需要方向键；第一候选是单字或者还没出候选时，退格还是删字母，那就用 `←`。

### 手动分隔

自动切分还是不理想时，可以用 `'` 强制断一刀：

- 全拼 / 小鹤双拼：`;`（如 `xi'an`）
- 微软双拼：`'`（分号被 `ing` 占了）

分隔符只帮你切，**不会进文档**。

### 模糊音：口音也能打出来

普通话不分 `zh/z`、`n/l`、`an/ang` 的人，以前得准确记住词库里的那个写法。打开模糊音
之后，按你的口音敲也算命中。

设置窗「模糊音」里九条规则各一个勾，按自己的口音挑：

| 规则 | 换了什么 | 例子 |
|---|---|---|
| `z = zh` | 声母 `z` ↔ `zh` | `zi` 也出「知」 |
| `c = ch` | `c` ↔ `ch` | `ci` 也出「吃」 |
| `s = sh` | `s` ↔ `sh` | `si` 也出「是」 |
| `n = l` | `n` ↔ `l` | `lan` 也出「南」 |
| `f = h` | `f` ↔ `h` | `fen` 也出「很」（部分方言） |
| `l = r` | `l` ↔ `r` | `lan` 也出「然」 |
| `an = ang` | 前鼻音 ↔ 后鼻音 | `san` 也出「桑」 |
| `en = eng` | 同上 | `gen` 也出「更」 |
| `in = ing` | 同上 | `jin` 也出「京」 |

**原样永远排在前面。** 模糊命中只是「补在后面」：敲 `zi`，第一位还是「自」，
「知」跟在后面；如果「知」你选得多了（超过 4 次），它会自己翻上来。

两条限制：

- **只在双拼模式下生效**。全拼模式（设置里切过去的那种）音节长度不固定，
  「声母位 / 韵母位」这个前提不成立，按位置换会换到隔壁音节上，所以不展开。
- 九条**默认全关**。普通话标准的话开了只会多出重码，按需勾。

### 上屏后联想下一个词

打完一个词上屏，候选窗会立刻给出「下一个常用词」：打「北京」之后是「时间」「大学」
「地区」，按数字键或拿鼠标点就上屏。

**什么长度的词都能接**：

- 一个字：打「我」→「觉得 / 知道 / 认为」（这些搭配来自 `我觉得` 这类复合词）
- 三个字：打「计算机」→「网络 / 软件 / 应用」
- 更长的词：整词查不到时会**取最长的已知后缀**。比如「今天北京」没有单独的词对，
  但「北京」有，所以照样给出「时间 / 大学」——「北京后面接什么」对这两者是同一件事。
  后缀至少留两个字，不会从「计算机」里截一个「机」去联想。

**两张表**：

- **内置表**（装完就有，约 2 万条 / 7000 个头词）：从词库里的复合词反推——`北京时间`
  拆成 `北京→时间`、`我觉得` 拆成 `我→觉得`。所以第一天就能联想出「北京 → 大学 /
  时间 / 地区」这种搭配。
- **你的表**（数据目录的 `next.txt`）：你自己打出来的词对。查询时**永远排在内置表
  前面**——你打过的搭配比词库统计更可信。

它不加载语言模型、不联网。设置窗「上屏后联想下一个词」可以关掉，右边的「清空」
清掉的是**你的表**（内置表清不掉，那是发货就带的）。

几条你可能会注意到的行为：

- **空格不选词**。联想是自动弹出来的，空格仍然是空格——要选就用数字键或鼠标点。
  （这点和搜狗不一样，是刻意的：每打完一个词都防着空格太累。）
- **按任何键都消失**：接着打字、按标点、按 Esc 都行，不用先「关掉」它。
- **只跳一次**：选了联想词之后不再继续往下联想。
- **打带标点的句子不联想**：`你好，` 之后已经在写下一句了，这时候给「你好」的
  后续词只会碍事。但这对词对**照记**，所以「他说：」之后下一个词仍然跟「他说」配对。

## 四、辅助码：给「音」再加一道「形」

音码打完之后，候选里还剩一堆同音字。`ji` 底下有 128 个单字，第一位是「机」，
可你要的是「记」——那就得翻好几页。

**辅助码就是这时候再加一道筛子**：音码打完，接着把字的「形状」用一两个字母输进去，
候选立刻从几十个缩到一两个。它不改变你怎么打字，只是让你少翻页。

设置窗「辅助码」里三选一（**新装默认是「小鹤音形」**）：

| 方案 | 键数 | 取码规则 |
|---|---|---|
| 关闭 | 0 | `Tab` 还给应用（在编辑器里就是缩进），不拦 |
| 自然码辅助码 | 1 键 | 部首读音首字母：`的`→白→`b`、`打`→扌(手)→`s` |
| 小鹤音形（默认） | 2 键 | 首部件 + 末部件，官方码：`打`→扌+丁→`fd`、`带`→带上+巾→`fj` |

**为什么默认是小鹤音形**：双拼方案默认就是小鹤，配套的形码又是官方码（和
`react.xhup.club` 反查逐字一致），两键比一键精确得多。自然码那一列是「部首读音
首字母」的简版，和官方自然码的部件表对不上（见下面「和官方自然码的差别」），
所以不当默认——想用去设置里点一下就行。**老配置不会被改**：你的 `config.ini` 里
存着 `assist_mode=`，以前选过什么还是什么。

**两套和输入模式互不干扰**：小鹤双拼配自然码辅助码、微软双拼配小鹤音形，都可以。
全拼模式下也能用（先按 `Tab` 再敲形码；只是「连打再按 `Tab`」那招不成立，因为全拼的
码长不固定，挪不出末尾哪几个键是形码）。

### 怎么用：三步

```text
ji                音码
ji → Tab          组合串末尾多出一个空格位，等着填形码
ji → Tab → m j    组合串显示成「ji mj」，候选只剩木字旁的字，「机」在第一位
```

敲完按空格就是「机」。组合串里那个空格只是分隔标记，**不会进文档**。

| 按键 | 作用 |
|---|---|
| `Tab` | 进入辅助码筛选；再按一次退出（形码清空，候选恢复原样） |
| 形码字母 | 缩小候选。自然码 1 键、小鹤 2 键 |
| `退格` | 删一个形码字母；删空就自动退出辅助码态 |
| `-` `=` / `↑` `↓` | 翻页（和平时一样） |
| `空格` / 数字 | 上屏 |
| `Esc` | 整个取消 |

**先连打、再按 `Tab` 也认**：小鹤把两键一次敲完（`dd` + `f` + `j`）再按 `Tab`，末尾能
当形码用的键会自动挪进辅助码，组合串直接变成 `dd fj`，不用退格重来。自然码同理，
只是只挪末尾 1 键。

### 小鹤音形（2 键）

规则：**首部件的声母 + 末部件的声母**。字根划分和码表用的是小鹤官方那一套，和
`react.xhup.club` 反查出来的码逐字一致——那里查到的码，这里可以直接用。

| 字 | 拆法 | 形码 |
|---|---|---|
| 打 | 扌(f) + 丁(d) | `fd` |
| 带 | 带字头(f) + 巾(j) | `fj` |
| 机 | 木(m) + 几(j) | `mj` |
| 记 | 讠(y) + 己(j) | `yj` |
| 计 | 讠(y) + 十(u) | `yu` |
| 玑 | 王(w) + 几(j) | `wj` |

有些字看不出规律，那是官方给「独体字 / 特殊字根」单独定的码，照抄就行，别硬猜：
`简` 是 `vo`、`明` 是 `oo`、`及` 是 `pn`。记不住就用 `/fc` 反查（见「快捷输入」）。

**例 1：同音字太多**

```text
ji → Tab → m j      →  机      （木 + 几）
ji → Tab → y u      →  计      （讠 + 十）
ji → Tab → y j      →  记      （讠 + 己）
ji → Tab → w j      →  玑      （王 + 几，平时排在很后面）
```

只敲第一键 `y` 的时候「计 / 记」都还在（都是言字旁），是第二键把两者分开的——
这正是 2 键比 1 键强的地方。

**例 2：给词定位**

词的辅助码只按**首字**算，所以它管的是「这一批同音字里，要哪个字开头的词」：

```text
dd → Tab → f        →  「带」开头的词（带上、带来、带进）
dd → Tab → r y      →  「代」开头的词（代表）
```

`dd` 底下有「大 / 代 / 待 / 带 / 戴 / 呆 / 贷」一串同音字，按 `f` 就只剩「带」那一支。

**例 3：形码打满，单字自动置顶**

小鹤形码打满 2 键后，形码和输入**完全相等**的单字会被顶到第一位，哪怕它不如同码的
词常用：

```text
jm → Tab → v o      →  简      （「简单」更常用，但打满了就该给这个字）
```

### 自然码辅助码（1 键）

规则：**取部首的读音首字母**。只有一键，所以它把同音字按「什么旁」分成二十来类。

| 字 | 部首 | 辅助码 |
|---|---|---|
| 的 | 白(bái) | `b` |
| 打 | 扌(手 shǒu) | `s` |
| 想 | 心(xīn) | `x` |
| 你 | 亻(人 rén) | `r` |
| 机 | 木(mù) | `m` |
| 简 | 竹(zhú) | `z` |
| 大 | 大(dà) | `d` |

**例 1：一个字一个键**

```text
da → Tab → s          →  打      （扌）
da → Tab → d          →  大      （大）
```

**例 2：同音字多的时候，一键就把它们切开**

`dd`（dai）底下这几个字，每个落在不同的键上：

```text
代 → r（人）    待 → c（彳，读 chì）   戴 → g（戈）
呆 → k（口）    贷 → b（贝）           带 → j（巾）
```

所以 `dd → Tab → j` 直接是「带」开头的词，不夹杂「代表 / 待机」。

**例 3：1 键也算「打满」**

自然码只取一键，所以按完这一键就算形码打满，**形码完全相等的单字同样会被顶到第一
位**：

```text
ji → Tab → m          →  机      （木）排在第一位，不用翻
```

只有**一个音节**时才算「打满」。打两字词时辅助码只是按首字筛，不会把首字顶到词
前面：

```text
nihc → Tab → r        →  你好    （你 是 亻，但这里打的是词）
```

**一键的天然极限**：同一部首的字分不开——`计` 和 `记` 的自然码都是 `y`（讠），
按完还得看候选。想分开就得多一个键，也就是下面这套。

**和官方自然码的差别**：这里是「部首读音首字母」的**简版**，不是自然码官方那套
部件表。官方表里 `日 / 月 / 曰 / 目` 都归 `o`（口诀「圆圆的 o」）、`扌` 归 `f`
（扶手）、`车 / 虫 / 臣 / 辰` 归 `i`（ch 的双拼键）、`竹 / 隹 / 舟` 归 `v`（zh
键）、`山 / 石 / 十 / 食` 归 `u`（sh 键）。简版按拼音首字母取，好处是不用背表、
看一眼部首就会，代价是从官方自然码带过来的肌肉记忆对不上——`打` 这里是 `s`，
官方是 `f`；`时` 这里是 `r`，官方是 `o`。

### 两套怎么选

| | 自然码辅助码 | 小鹤音形（默认） |
|---|---|---|
| 键数 | 1 | 2 |
| 怎么记 | 念一遍部首名（白、手、心、人） | 记小鹤官方字根（一百多个） |
| 区分力 | 同部首的字仍然重码 | 首末两道，重码很少 |
| 适合 | 偶尔用、不想背字根 | 天天用、想要「打满就出那一个字」 |
| 同音对比 | `计` / `记` 都是 `y` | `计`=`yu`、`记`=`yj` |

随时能换：设置里选完立刻生效，已经打了一半的码接着敲就行。

### 五条容易踩的

1. **筛选是过滤，不是排序。** 形码筛不到就是**一条候选都没有**，翻多少页都找不到
   ——形码写错不会「排到后面」，而是直接空窗。这时按 `Tab` 退出，或退格删掉形码。
2. **键数有上限**：自然码 1 键、小鹤 2 键。多敲一个字母 = 筛空。
3. **辅助码态里进不了分词。** 想逐段改长句，先按 `Tab` 退出。
4. **词只按首字筛。** 第二个字的形状不参与，所以给词加形码不会「越筛越准」；
   想让词更准，把音码打全，让整串本身就是个词。
5. **表里查不到的字没有辅助码**（少数生僻字），按了 `Tab` 之后它会被筛掉。

### 和「3 键直出」的关系

设置里那个「**3 键直出单字**」（默认关）就是省掉 `Tab`：第 3 键直接当形码。

```text
自然码：da + s            →  打      （不用按 Tab）
小鹤：  dd + f            →  带      （第 3 键先当第一道形码）
        接着再敲 j        →  dd fj   →  带
```

它是在猜，猜错会自动退回：继续打下去如果整串本身是个词（`ykwf` → 英文），就并回音码
出词；筛空了也会并回。**自己按 `Tab` 拆的辅助码不会被自动撤销**——那是明确意图，
要退出就再按一次 `Tab`。

## 五、快捷输入（先敲 `/`）

按 `/`（问号那个键），后面接命令码。**只打首字母也行**：
`/r` 就等于 `/rq`。只打一个 `/` 会列出所有命令的预览，用数字挑。

**手机（Android）上一样能用**：中文态下敲 `/` 就进快捷输入，候选条直接
摆出结果，点一条或按空格选第一条上屏。敲 `/` 本身（只打引导符就按空格）
仍然是上屏一个 `/`。不想要了：退格删到只剩 `/` 再按一次退格，
或者按回车、切换中英。

| 输入 | 得到 |
|---|---|
| `/rq` | `2026年10月23日` / `2026-10-23` / `2026/10/23` / `2026.10.23` / `10月23日` / `23日` |
| `/sj` | `17:40` / `17:40:06` / `下午5点40分` / `下午5:40` |
| `/xq` | `星期四` / `周四` |
| `/dt` | `2026-10-23 17:40:06` / `… 17:40` / `2026年10月23日 17:40` / `… 星期四` |
| `/ts` | Unix 秒 / Unix 毫秒 |
| `/nl` | 农历：`农历丙午年九月十四` / `丙午年九月十四` / `九月十四` |
| `/gz` | 干支四柱：`丙午年 戊戌月 庚午日 壬午时` / `丙午 戊戌 庚午 壬午` / 不带时的三柱 |
| `/jq` | 下一个节气：`2026年11月7日 立冬` / `11月7日 立冬` / `立冬` |
| `/fc` | 反查剪贴板里的汉字：`璇 xuan+wr  玑 ji+wj` / `璇玑  xrji → wr` |
| `/c…` | 算式 / 数字 / 日期，见下面 |
| `/u…` | Unicode 码点，`/uuid` 出随机 UUID |
| `/v…` | 金额，财务大写在前，见下面 |

### `/c` 计算：算式、中文数字、金额大写

`/c` 后面接数字和运算符，按内容自动分三种：

| 输入 | 得到 |
|---|---|
| `/c1+2` | `3` / `1+2=3` |
| `/c2*(3+4)` | `14` / `2*(3+4)=14` |
| `/c123` | `一百二十三` / `壹佰贰拾叁` / `一百二十三元整` / `壹佰贰拾叁元整` |
| `/c123.5` | `一百二十三点五` / `壹佰贰拾叁点伍` / `一百二十三元五角` / `壹佰贰拾叁元伍角` |
| `/c1998-3-8` | `一九九八年三月八日` / `1998年3月8日` / `1998-03-08` |

运算符：`+` `-` `*` `/` `^`（乘方）、`(` `)`、小数点。`*` 也可以按 `x`，
省得去够 Shift+8。全都支持小键盘。

**进了 `/c`，数字键就归算式了**，不再选候选——两种含义抢同一个键，只能挑一个。
要看/换候选：空格上屏第一项、左右键换、上下翻页、或者直接点鼠标。

几条边界：

- **年份必须是四位**：`/c98-3-8` 是减法（得 87），不是 1998 年 3 月 8 日。
  猜世纪猜错了比不支持更糟。
- `1998.3` 是**小数**（一千九百九十八点三），不是「1998 年 3 月」。
- 月日不合法就退回算式：`/c1998-2-30` 得 1966。

### `/u` 字符：码点与 UUID

- `/u4e00` → `一`，`/u1f600` → 😀（十六进制码点，最多 6 位）
- `/uuid` → 一条随机 v4 UUID（小写 / 大写两种写法）

### `/v` 金额：数字 → 财务大写

开票场景专用：候选里只有金额，**大写在前**，小写读法随后当参考。小数只认
角分两位；刚敲完 `.`（`/v123.`）按整数给，候选不闪。

- `/v123` → `壹佰贰拾叁元整` / `一百二十三元整`
- `/v123.5` → `壹佰贰拾叁元伍角` / `一百二十三元五角`
- `/v123.05` → `壹佰贰拾叁元零伍分`（有分无角，元后补零）
- `/v0.5` → `伍角`（不足一元不写「元」）

### 自定义短语：一个码出一整段文本

**这条不用敲 `/`**，直接打码就出。设置窗里点「编辑自定义短语…」打开
`custom.txt`（文件不存在时会生成一份带注释的模板）：

```text
# 编码<TAB>文本
dz	北京市朝阳区{year}年{month}月{day}日
sfz	110101199001011234
qm	此致
```

规则：

- **编码**是 1–32 个小写字母，就是平时打的码。双拼模式写双拼码
  （`dz` 是两键），全拼模式写全拼串。
- **文本**支持时间变量：`{year}` `{month}` `{day}` `{hour}` `{minute}`
  `{second}` `{weekday}`。年月日不补零（`11月4日`），时分秒补两位（`09:05`），
  `{weekday}` 是「一」到「日」。`{{` `}}` 输出花括号本身，认不出的 `{…}` 原样保留。
- **同一个码可以写多行**，按文件顺序排在候选最前面。
- 改完切回输入窗口就生效（每次切换窗口会看一眼文件有没有变）。

自定义短语和「自造词」不是一回事：自造词是**学的**（分词上屏一次记一条，和词库候选
一起按词频排），自定义短语是**写的**（直接顶到候选第一位，不用先选几次让它学会）。
手动置顶仍然压在它上面——临时想换一个的时候，置顶更近。

### `/fc` 反查：这个字该怎么打

复制一个打不出来的字或词，敲 `/fc`：

- **第一条候选**是逐字明细：`字 全拼+形码`，例如 `璇 xuan+wr  玑 ji+wj`。
- **第二条候选**是能直接照着敲的连打串：`璇玑  xrji → wr`——先敲 `xrji`，按 `Tab`，
  再敲 `wr`。单字时这一条就是完整的码（`玑` → `jiwj`）。

形码跟着设置里的辅助码方案走（自然码 1 键 / 小鹤音形 2 键），音码跟着输入模式走
（双拼模式给双拼码 `xr`，全拼模式给 `xuan`）。读音取自本输入法自己的词库，所以
给出来的码一定能敲出来。

### 农历 / 干支 / 节气说明

- **`/nl` 农历**：按农历年输出干支年（**按春节换年**）。闰月会写成「闰六月」。
- **`/gz` 干支**：这是**四柱（八字）**，不是农历年。年柱**按立春换**、月柱**按节气换**、
  日柱**按子时（23:00）换日**。所以春节前后几天、立春前后几天，`/nl` 和 `/gz` 的
  年份会不一样——这是对的，两者本来就是两套历法。
- **`/jq` 节气**：给你**最近的下一个**节气，精确到日。如果今天正好是节气当天，
  给的就是今天这个。

> 农历 / 干支 / 节气的计算统一来自 [Tyme](https://6tail.cn/tyme.html)（MIT 许可），
> 节气算法引自寿星天文历。三个功能共用同一套儒略日，不会互相打架。

> 为什么引导符是 `/`：顿号只留 `\` 一个键（搜狗习惯）就够了，`/` 位置好记好按，
> 拿来当功能入口更划算。中间一度搬到反引号，但那个键太偏、记不住，又换回来了。
>
> 代价是中文态下 `/` 不再出顿号。**想打斜杠**：敲 `/` 再按空格或回车——
> 只打了引导符本身时，第一候选就是 `/` 本身（全角模式是 `／`），命令预览排在后面。
>
> **已经打了一半编码时按 `/`**：会先把你当前选的候选上屏，再输出斜杠
> （`de` + `/` → `的/`）。以前这个键会被直接吞掉，斜杠凭空消失。

## 六、状态浮窗与设置

屏幕右下角有一条小横条（可以拖动，位置会记住；也可以让它跟随光标）：

| 按钮 | 作用 | 快捷键 |
|---|---|---|
| 中 / 英 | 切换中英文 | 单击 `Shift` |
| 全 / 半 | 全角符号宽度：开着时英文态下的标点用全角形式（，．；，占一个汉字宽）。中文态恒为中文标点 | 点这个按钮 |
| 符号 | 打开符号软键盘（9×5 网格，点击即插入） | — |
| 设置 | 打开设置窗口 | — |

**鼠标停在按钮上会冒出一个气泡**，告诉你它是干什么的、怎么切。全角 / 半角没有键盘
快捷键，点一下按钮就切——这个开关不常用，不值得占一个全局组合键。

设置窗口的**标题栏带版本号**（`飞鹤输入法 · 设置 · 0.3.18`），反馈问题时截个图就能
知道是哪一版，不用去翻安装包。

设置窗口里能改：

- **输入模式**：双拼 / 全拼
- **启动默认**：中文 / 英文——每次激活输入法（切窗口、开机）进入的模式（默认中文）。
  单击 Shift 切换只影响当前会话
- **双拼方案**：小鹤 / 微软
- **辅助码**：关闭 / 自然码 / 小鹤音形（默认）——打完码按 `Tab` 再加一道「形」的筛选，
  详见「辅助码」一章
  - 为什么必须按 `Tab`：`ddj` 也是「代价 / 待机 / 带进」这些词的合法前缀，
    键盘分不清你要的是「带 + 部首 j」还是「带 + 价没打完」，所以得给一个明确的进入信号
  - **3 键直出单字**（默认关）：打开后第 3 键直接当形码，`ddj` 不按 `Tab` 就出「带」。
    它是在猜，猜错会自动并回音码；用户自己 `Tab` 拆的不在此列
  - 官方反查工具的码（`react.xhup.club`）和这里完全是同一套；懒得查工具就复制那个字，
    敲 `/fc`
- **皮肤**：浅色 / 深色 / 护眼
- **字形**：简体 / 繁体
- **全角符号**（默认开）：只管标点**宽度**。中文态恒出中文标点；英文态标点默认
  半角，开了全角换成全角英文标点（，．；［］……占一个汉字宽，和中文标点是不同的
  字符）。字母、数字不受影响
- **浮窗跟随光标**
- **候选窗何时收起**：自动（默认）/ 始终弹出 / 始终不弹（见下）
- **动态调频**（按你实际选词调整候选顺序）+ **自造词**（自动记住你拼出来的新词）+ **重置**
- **置顶**：看当前置顶了哪些码 + 一键清空
- **降权**：看按下去多少条 + 一键清空（`Ctrl`+左键点候选，见前文）
- **上屏后联想下一个词**（默认开）：打完一个词把「下一个常用词」摆出来，只学你自己的
  用词（见「候选窗怎么操作」一章）。右边的「清空」会丢掉学到的全部词对
- **启用玄学词库**（默认关）：干支、易经、奇门、六壬、六爻、神煞那 600 多条术数词
  参不参与候选，见「词库」一章
- **词库**：统计、导入（含「从搜狗导入…」「细胞词库…」）、导出、编译个人词库

窗口最下面是「**关于**」：一段项目自述和仓库地址
`https://github.com/icefairy/feihe`。点那行地址或旁边的「打开项目主页」，会用你的
默认浏览器打开 GitHub 页面（输入法自己不联网，只是把地址交给系统）。

### 屏幕缩放 150% 也照样清楚

Windows「显示设置 → 缩放」调成 125% / 150% / 200% 之后，飞鹤的候选窗、状态浮窗、
符号面板、设置窗会**跟着按同样比例放大**：字、行高、内边距、按钮宽度、九宫格格子
一起变大，不会出现「窗口大了但字还是那么小」或者「点第 3 个候选上屏了第 4 个」。

多块屏幕缩放不一样也没关系：把窗口拖到另一块屏，它会按那块屏的比例重排。

如果你的程序是**很老的那种**（自己不做 DPI 适配的，比如十年前的小工具），Windows
会替它把整个界面放大一遍；飞鹤能认出这种情况，按 100% 画，不会放大两遍。

### 全屏游戏里怎么打字

**默认就能用，不用改设置。** 全屏游戏里飞鹤照常弹自己的候选窗——现代 Windows 上的
「全屏游戏」绝大多数是**无边框窗口化全屏**（D3D 的独占全屏从 Windows 10 起也被系统的
「全屏优化」接管了），候选窗盖得上去。

只有第一次会有点动静：**画面可能闪一下**。那是 Windows 发现「有窗口盖在全屏程序上」，
退出全屏优化状态、让游戏重建一次画面。任何置顶小窗都会引起这一次（QQ 消息提示也一样），
躲不掉，但**只发生一次**，之后打字就不再闪。

嫌这一下烦，可以到设置里把「候选窗」改成**始终不弹**——代价是全屏里看不见候选，只能
盲打（空格出第一个、数字键按顺序选）。

还有一条更好的路：如果游戏按 TSF 的 **UILess** 方式启动（主流引擎都做了：LOL、原神、
魔兽世界、CS2…），系统会告诉飞鹤「别自己画，把候选数据交给我」，候选就由**游戏自己**
画在它的界面里——零闪烁、零遮挡，字体风格也是游戏自己的：

- 数字键选词、`-` `=` 翻页、方向键移动，和桌面上手感一致；
- **自动生效，没有开关**——游戏要，飞鹤就给；
- 游戏不接（或者接了却不画），飞鹤立刻退回自己画。

### 全屏时哪些窗口收起来

**默认全自动，不用改设置。** 打字的瞬间飞鹤会问一下 Windows「现在是不是全屏」，然后：

| 场景 | 候选窗 | 右下角浮窗 |
|---|---|---|
| 全屏游戏（D3D 全屏） | **照常弹** | 收起来 |
| 全屏应用（商店版游戏、视频 App） | **照常弹** | 收起来 |
| 演示 / 投影模式 | 不弹，候选写进编码后面 | 收起来 |
| 普通桌面 | 照常弹 | 显示 |

两边的道理不一样：**候选窗是敲了键才出现的**，全屏游戏里正需要它；**浮窗是常驻的**，
全屏时会一直挡在画面上，所以任何全屏场景都收起来。

只有演示 / 投影模式会把候选窗也收起来：屏幕在给别人看，冒个候选窗上去很尴尬。这时
候选改写成纯文本跟在编码后面（那是应用自己画在界面里的，不是我们弹的窗口）：

```text
nihc  1.你好 2.拟好 3.你号 …
```

数字键照样选，`-` `=` 照样翻页，空格出第一候选。没有候选窗可点，所以**鼠标选词在这个
状态下不可用**。

**手动档**在设置里「候选窗」那一行，三选一：

- **自动**（默认）：按上面的规则
- **始终弹出**：连演示 / 投影时也弹
- **始终不弹**：远程桌面、虚拟机控制台，或者真·独占全屏游戏（一弹窗就把游戏踢成
  窗口化的那种）——这种情况下候选会写进编码后面

**临时切换**：`Ctrl+Shift+U` 按一次切到相反状态，再按一次回到「跟随设置」。它**不写配置**，
只管当前这个窗口——是应急键，不是设置项。浮窗被藏起来时，这也是唯一能回到设置窗的入口
（没有浮窗就没有「设置」按钮）。

（万一真锁住了：把 `%LOCALAPPDATA%\Feihe\config.ini` 里的 `popup=` 改成 `auto`。）

> **做不到的**：如果某个程序既不走 UILess、也不显示组合串（极少数完全自绘输入框的
> 引擎），飞鹤在里面一个字也打不出来。那种场景只剩「键盘钩子 + 模拟按键 + 注入进程
> 画候选」的外挂式工具，飞鹤不做：这类工具要常驻监听全部按键、往游戏进程里塞代码，
> 反作弊会直接判成外挂，风险和维护成本都远超收益。

## 七、词库

手机端的「个人词库」在设置页单独一张卡片：导入 / 导出 / 编译 / **从搜狗导入**。
导入导出用的是电脑端同一份纯文本（每行「词 + Tab + 全拼」），记事本能打开，能拷来拷去。
**编译不是必做的**：不编译也能查（走文本回退），编译了查询更快。

「从搜狗导入」收的是搜狗自己的格式——从[搜狗词库网站](https://pinyin.sogou.com/dict/)
下载的 `.scel` 细胞词库、搜狗目录里的 `sgim_gd_usr*.bin` 都行。词从文件里抠出来之后
**现场自动注音**（和电脑端「细胞词库…」是同一份解析代码），所以不需要你准备拼音。
导完会弹一个框，把「读入几个文件 / 解析多少条 / 新增多少条」逐项列出来。

内置 7.5 万条词、8573 个单字（《通用规范汉字表》可编码的全收，再补 GB2312 独有的字）。
分类词表由 `tools/gen_extra.py` 生成，按文件分开：日常常用词、IT 行业词、地名、
通用药品名、中药名、中成药名，以及术数类的六十甲子、六十四卦、神煞名、奇门遁甲、
大六壬、六爻。前六类编进主词库，**术数那六类单独打成一个包**，见下面「玄学词库」。

够日常，但**不是「什么都有」**——专业术语、网络新词、人名地名基本查不到，可以自己补：

1. **细胞词库**：设置窗 → 「细胞词库…」，直接选一个从[搜狗词库网站](https://pinyin.sogou.com/dict/)
   下载的 `.scel` 文件——**跟本机装没装搜狗无关**。自动注音后并进个人词库，
   和「从搜狗导入」一样只并还没有的词、立刻编译生效。
   > 词库内容的版权归原上传者与搜狗所有：导入仅供个人使用，别把提取出来的词再分发。
2. **从搜狗导入**：设置窗 → 「从搜狗导入…」。它会自己找搜狗装在哪儿，
   把打字历史（`sgim_gd_usrbg.bin`）、用户词库（`sgim_gd_usr.bin`）和细胞词库
   （`Scd\*.scel`）里的词捞出来，自动注音后并进你的个人词库，打完立刻生效。
   - 只并**还没有的**词，反复点不会越并越多；
   - 找不到搜狗（装在别的盘、绿色版）时它会问你要不要手选文件夹，
     一般选 `<搜狗安装目录>\用户数据\SogouPY.users\<一串数字>`；
   - 结果看设置窗那条灰字（`已导入 N 个新词（M 个文件，跳过 K 条）`），
     扫了多少条、多少条是逐字注上音的，细节记在 `<安装目录>\feihe.log`。
   - **在别的程序里要切换一次输入法才生效**（个人词库是每个进程各自加载的）。
   也可以手工准备一个「每行 `词<TAB>全拼`」的文本，用「导入词库…」导入。
3. **编译个人词库**：导入后会自动编译；手改过文本的话点一下「编译个人词库」。
   二进制版本走内存映射，多个程序共用一份，更省内存也更快。
   它编译的是你的 `user_dict.txt`，不是程序本身。还没导入过个人词库时那个文件不存在，
   点了只会提示「还没有个人词库」，不是出错。
3. **动态调频**：你选了哪个词，下次它就往前排——只在**同样键数**的候选之间调，
   所以敲 `ig` 第一位永远还是「成」，不会因为你常打「程序」就被顶掉。
   不想要就在设置里关掉，或点「重置」。
4. **自造词**：词库里没有的词，你用分词模式一段一段拼出来的，飞鹤会自动记住，
   下次同样的码打满就直接出（存的是全拼，换方案也不丢）。想忘掉就点「重置」。

用户词库的源文件是数据目录下的 `user_dict.txt`（设置窗「数据目录」那行写着具体
路径，一般就是安装目录），可以手工编辑、可以导出。

### 玄学词库（默认关，需要时勾一下）

术数那批词——六十甲子（`甲子` `壬寅` `癸亥`）、六十四卦（`水雷屯` `天地否`）、
神煞（`天乙贵人` `羊刃` `华盖`）、奇门（`值符` `生门`）、大六壬（`四课三传`）、
六爻（`纳甲` `世爻` `旺相休囚死`）——一共 600 多条，**单独打成一个词库包，默认不参与候选**。

去设置窗勾上「**启用玄学词库**」（Android 在「学习」卡片里），勾完立刻生效，
不用重启、不用切程序。

为什么默认关：

- 这些词的读音对多数人没有意义，混在通用词库里唯一的效果是**把单键 / 短码的重码变多**
  ——敲 `g` 的时候多出一堆「庚」「癸」，谁都用不上；
- 需要它的人（算命的、研究中医学的）是一整摊，一次勾选全回来，不用挑挑拣拣。

所以做成**一个开关**而不是十几个分类勾选框：其余分类（中医、IT、地名…）属于
「偶尔能打到就好」，留在主词库里正好，没必要让用户去决定。

> 老版本升级上来的用户会感觉「以前能打出来的『庚』『值符』不见了」——这是刻意的，
> 勾一下上面那个开关就全回来了。

用户词库的源文件是数据目录下的 `user_dict.txt`（设置窗「数据目录」那行写着具体
路径，一般就是安装目录），可以手工编辑、可以导出。

## 八、标点与符号

**用哪套标点跟中英切换走**：中文态下不带 Shift 的标点键输出中文标点（恒定，
与全角开关无关）；英文态标点原样进应用（半角），全角开关开着时换成全角英文标点。

| 键 | 中文态输出 | 英文态（全角开） |
|---|---|---|
| `,` `.` | `，` `。` | `，` `．` |
| `;` `'` | `；` `’` | `；` `＇` |
| `[` `]` | `【` `】` | `［` `］` |
| `\` | `、`（顿号只留这一个键） | `＼` |
| `-` `=` `/` | `－` `＝` `／` | `－` `＝` `／` |
| `Shift + 4` | `￥`（人民币符号） | `$` |
| `Shift + 6` | `……`（省略号） | `^` |
| `Shift + -` | `——`（破折号） | `_` |
| `Shift + ,` `Shift + .` | `《` `》`（书名号） | `<` `>` |
| `Shift + 1` | `！` | `!` |
| `Shift + /` | `？` | `?` |
| `Shift + ;` | `：` | `:` |
| `Shift + 9` `Shift + 0` | `（` `）` | `(` `)` |
| `Shift + =` | `＋` | `+` |
| ``Shift + ` `` | `～` | `~` |
| `Shift + '` | `“` `”`（交替，见下） | `"` |

> **Shift 组合的规则照搜狗**：中文态下这些键出中文标点，英文态还是 ASCII。
> 前四个（`￥` `……` `——` `《》`）在中文里**没有半角对位**，拿 ASCII 凑不出来；
> 其余几个是中文标点体系里的对位（`！？：（）＋～`）。和搜狗、微软拼音一致。
>
> **双引号是交替的**：第一次按 `Shift + '` 出 `“`，第二次出 `”`，第三次又回到 `“`。
> 这是唯一能保证引号成对的办法。单引号 `'` 不交替，恒出 `’`——`’` 后面常紧跟 `s`
> （英文所有格）或表示分钟，交替会让这些场景每次多按一下。
>
> 前提是**你那个键盘布局上 `Shift+这个键` 本来就出对应的 ASCII**：法语 AZERTY 的
> 数字键要按 Shift 才出数字（`Shift+4` 给 `4`）、德语 `$` `_` 要走 AltGr，那些布局
> 飞鹤一律不动，交还给系统。这是刻意的——宁可不出中文符号，也不能打出你没按的字符。

> `@` `#` `%` `&` `*` 交给应用自己出（中文里没有对位，`@` 还要留给邮箱）；
> `|` `{` `}` 也不换——它们在中文写作里基本只出现在代码中，换了会让在中文态写代码的
> 人吃亏。需要这些半角符号时切到英文态。

组合串还没上屏时按标点键，会先把候选上屏、紧跟着粘上标点，
**不会**出现「，,」两个字符。

## 九、常见问题

**装了但输入法列表里没有「飞鹤拼音」**
键盘列表由外壳缓存，注销一次或重启。仍然没有的话，用管理员权限重跑一遍安装包。

**首次运行被 SmartScreen 拦住**
安装包没有代码签名。点「更多信息 → 仍要运行」。

**更新版本后还是旧行为**
覆盖安装完成后，点一下任意输入框即可——安装时已经重启过输入法进程，新 DLL 会在下次
输入时自动加载，不用注销也不用重启。

**候选窗位置不对 / 不跟着光标走**
设置里关掉「浮窗跟随光标」试试；某些全屏程序或游戏里候选窗位置由宿主决定。

**游戏全屏时第一次打字，画面闪一下**
这是 Windows 的「全屏优化」退出造成的：系统发现有窗口盖在全屏程序上，就让游戏重建一次
画面。任何置顶小窗都会引起这一次，躲不掉，但**只发生一次**，之后打字不再闪。如果游戏
支持 TSF UILess（主流引擎都支持），候选由游戏自己画，连这一次都不会有。
实在不想看到，把「候选窗」改成 **始终不弹**。

**在游戏里完全打不出字**
先确认装的是不是新版——2026-10 之前「候选窗」的「自动」档会把全屏游戏也当成
「别弹窗」，结果候选窗不弹、游戏又不画编码，看起来就是「能敲键盘但屏幕上什么都没有」。
现在「自动」只在演示 / 投影时才收候选窗，全屏游戏照常弹。

如果还是不行：把游戏从**独占全屏**改成**无边框窗口 / 窗口化**；或者把「候选窗」改成
**始终不弹**，让候选变成纯文本跟在编码后面（这时要靠数字键和空格，看不见也能按顺序选）。
见「全屏游戏里怎么打字」和「全屏时哪些窗口收起来」两节。

**改了双拼方案，别的程序没立刻变**
已经打开的进程要重新激活一次（点一下那个窗口）才读到新配置，不用重启。

**安装目录里有一堆 `feihe.dll.old-*`**
覆盖安装时旧 DLL 常被输入法进程占着，只能改名等重启删。现在安装结束时会自动重启输入法
进程（ctfmon），残留的 `.old` 文件会被顺手清掉；万一有漏网的，重启后可手动删除，
不影响使用。

**想彻底卸载**
「设置 → 应用 → 已安装的应用 → 飞鹤拼音 → 卸载」，或运行安装目录里的 `uninstall.exe`。
卸载会清掉 COM / TSF 注册和安装目录，但**不会删你的个人数据**（见下）。

## 十、数据与隐私

- **不联网**。程序里没有任何网络代码（连导入表里都没有 `wininet` / `winhttp` / `ws2_32`），
  不是「承诺不上传」，是「没写这个功能」。
- **不要账号**，没有广告，没有热点推送。
- **密码框里一个字都不接管**：登录框、支付密码、Wi-Fi 密码这类输入位置，输入法
  不弹候选、不组组合串、不把字母变成汉字，按键原样进应用。判据是 TSF 的
  `IS_PASSWORD` 输入范围，加上经典编辑框的 `ES_PASSWORD` 样式位（两套都要，
  老程序不设前者）。单击 Shift 切中英在密码框里照常可用。
- 你的数据全在**安装目录**（默认 `%LOCALAPPDATA%\Feihe\`）下：

| 文件 | 内容 |
|---|---|
| `config.ini` | 设置项 |
| `freq.txt` | 动态调频的学习记录（纯文本 `码<TAB>词<TAB>次数`，删掉即重置） |
| `phrases.txt` | 自造词（纯文本 `词<TAB>全拼<TAB>次数`，删掉即全部忘掉） |
| `pinned.txt` | 手动置顶（纯文本 `编码<TAB>词`，删掉即全部取消） |
| `demoted.txt` | 手动降权（同上格式，删掉即全部恢复） |
| `next.txt` | 你自己的联想词对（`上一个词<TAB>下一个词<TAB>次数`，删掉即清空；内置的那 2 万条编译在程序里，不在这个目录） |
| `custom.txt` | 自定义短语（纯文本 `编码<TAB>文本`，删掉即全部取消） |
| `user_dict.txt` | 你的个人词库（源文件，可编辑） |
| `user.bin` | 上面那个文件编译出来的二进制 |

**备份 = 压缩这个文件夹。** 所有数据都和程序放在一起，所以拷走安装目录（或者直接压成
zip）就是一份完整备份：换机、重装、给第二台电脑用，解压回去就能接着用，设置和打字的
习惯都跟着走。恢复时先退掉输入法（切到英文键盘即可）再覆盖文件，否则可能被占用。

卸载不会动这个目录（数据文件留在原处，目录因而不会被删）。想彻底清干净，卸载后手动删除整个安装目录即可。

> 装到只读位置（比如手动装进 `C:\Program Files`）时，程序写不进去会自动把数据放到
> `%APPDATA%\Feihe`，设置窗底部的「数据目录」会显示**实际在用**的那个路径——以它为准。

## 十二、输入法不见了怎么办

装完更新后，如果语言列表（Win+空格）里看不到「飞鹤拼音」，「添加键盘」里也没有，
或者设置里出现一个灰色的「不可用的输入法」——**不用重装**：打开安装目录，
**右键 `Feihe-Repair.exe` → 以管理员身份运行**。

它会先检查一遍注册状态，再决定要不要动手：

- **一切正常**：直接弹「当前注册状态正常，不需要修复」，**一个字都不写**。这时候如果
  你在 Win+空格里还是看不到它，多半是列表缓存没刷新——注销后重登一次即可。
- **有缺项**：窗口里会列出缺了什么（`[need]` 开头的那几行），然后重新注册 COM / TSF
  组件和键盘列表，几秒钟完成，最后弹「修复完成」。

修复过程**不改动任何文件**，不会动你的词库、自造词和个人设置，也不影响正在运行的程序
——浏览器、微信开着也能修，不用关掉重开。

> 必须用管理员身份运行：注册信息写在系统的机器级注册表里（`HKLM`），普通权限写不进去。
> 以前版本写在用户级注册表里，看起来能装好，但系统的输入法列表根本读不到——这就是
> 「多出一个不可用的输入法、却切不到飞鹤」的原因。

修完用 Win+空格或 Ctrl+Shift 切换；如果列表里还是看不到，注销后重新登录一次
（语言列表由 shell 缓存，注销最快）。

找不到安装目录时：控制面板「程序和功能」里找到「飞鹤拼音」，右键属性里「位置」那一栏
就是；默认是 `%LOCALAPPDATA%\Feihe`。

- **打字**：默认小鹤双拼（`nihc` 出「你好」），查不到时自动按全拼再试；设置页可切全拼。
- **选词**：点候选；或打开「数字选词行」后点 1–9。空格永远选第一个。
- **改长句**：打 `vhsjli` 出「张三李」，候选条画成 `[张三][李]`，点哪段就展开那段的
  候选改词，改完按空格整句上屏。
- **大写**：单击 ⇧ 只管下一个字母；**长按 ⇧** 锁定连续大写，再点一下解除。
- **语音**：按住状态条上的 🎤 说话，松手上屏（首次要在设置页授权麦克风）。全程离线，
  录音不上传、不落盘，句末自动补一个标点。
- **备份**：设置页「数据」→ 导出 / 导入 zip，用系统文件选择器，不申请存储权限。
- **设置入口**：键盘状态条齿轮、系统设置里的「设置」、桌面图标，三个都指向同一页。
