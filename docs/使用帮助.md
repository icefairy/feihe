# 飞鹤拼音 · 使用帮助

> 版本 0.2.0 ｜ Windows TSF 中文输入法 ｜ 原生小鹤双拼
> 不联网、不弹窗、无账号。安装包 1.36 MB，装完约 6.0 MB。
>
> 这份文件就在安装目录里（默认 `C:\Program Files\Feihe\使用帮助.md`），
> 用记事本、VS Code 或任何 Markdown 阅读器都能打开。

## 一、装完之后要做的两件事

1. **把飞鹤加进键盘列表**（只需要做一次）
   打开「设置 → 时间和语言 → 语言和区域 → 中文(简体，中国) → ⋯ → 语言选项 →
   添加键盘 → 飞鹤拼音」。
   如果列表里还没出现「飞鹤拼音」，**注销一次或重启**——键盘列表由系统外壳缓存。

2. **切过去**
   按 `Win + 空格`（或 `Ctrl + Shift`）在输入法之间轮换，任务栏右下角会显示「中」。

> 装的时候如果 Windows 弹「已保护你的电脑」，点「更多信息 → 仍要运行」。
> 安装包没有买代码签名证书，这是正常的，不是文件损坏。

## 二、怎么打字

**飞鹤不是全拼，是小鹤双拼。** 每个音节固定两个键：**声母键 + 韵母键**。

```text
声母键位
  zh = v    ch = i    sh = u
  其余声母就用字母本身：b p m f d t n l g k h j q x r z c s y w

韵母键位
  Q iu    W ei    E e     R uan   T ue    Y un    U u/sh   I i/ch   O o/uo   P ie
  A a     S ong   D ai    F en    G eng   H ang   J an    K uai    L iang
  Z ou    X ia    C ao    V ui/zh B in    N iao   M ian
```

口诀：**秋闱软月云梳翅，松拥黛粉更航安，快莺两望奏夏蛙，撇草追鱼滨鸟眠。**

几个例子：

| 想打 | 全拼 | 双拼按键 |
|---|---|---|
| 你好 | ni hao | `nihc` |
| 中国 | zhong guo | `vsgo` |
| 世界 | shi jie | `uijp` |
| 按钮 | an niu | `annq` |
| 是 | shi | `ui` |

**零声母**（没有声母的音节）：

- 单字母韵母：**重复该字母**。啊 `aa`、哦 `oo`、额 `ee`
- 双字母韵母：**保持全拼**。爱 `ai`、安 `an`、欧 `ou`
- 三字母及以上：**用韵母所在的键**。昂 `ah`、鞥 `eg`

**打错了**：退格删一个键，`Esc` 整串取消。

**中英文切换**：**单击一下 Shift**（按住期间按过别的键就不算单击，`Shift+A` 照常是大写 A）。
切到英文后所有按键原样进应用，候选窗不弹。

### 一级简码：一个键一个字

26 个字母键各配一个「这个键底下最常用的字」。敲一个键，它就是第一候选，
空格直接上屏——不用翻、不用选：

```text
q 去   w 我   e 二   r 人   t 他   y 一   u 是   i 出   o 哦   p 平
a 啊   s 三   d 的   f 非   g 个   h 和   j 就   k 可   l 了
z 在   x 小   c 才   v 这   b 不   n 你   m 没
```

口诀：**去我二人他，一是出哦平；啊三的非个，和就可了；在小才这，不你没。**

几个看着奇怪的位置都有原因：`u` 在小鹤双拼里兼 `sh`，所以「是」在 `u`；
`v` 兼 `zh`，「这」在 `v`；`i` 兼 `ch`，「出」在 `i`。

两点要说明：

- **只对单键生效**。敲第二个键就回到正常排序（`d` 出「的」，`de` 按词频排）。
- **一简字排在动态调频前面**。不管你把「大」选过多少次，`d` 的第一个仍然是「的」——
  这是打字的肌肉记忆，不该被偶发的学习结果顶掉。真想让别的字排第一，用下面的**置顶**。

### 想换掉一简字？用置顶

`Ctrl` + 数字 = 把这个候选**钉**到当前编码上，以后打这个码它永远第一。
对已经置顶的那个词再按一次 `Ctrl`+数字就是**取消置顶**。

| 例子 | 效果 |
|---|---|
| 打 `d`，按 `Ctrl+2` 选「大」 | 以后 `d` 第一个就是「大」，不再是「的」 |
| 打 `iuliqi`，按 `Ctrl+3` 选「处理器」 | 以后 `iuliqi` 直接出「处理器」 |
| 打 `d`，选中已经是置顶的「大」，`Ctrl+数字` | 取消置顶，`d` 回到「的」 |

置顶压过一简码、压过动态调频、压过词库词频。记录在
`%APPDATA%\Feihe\pinned.txt`（一行「编码<TAB>词」），可以手改、可以整个删掉；
设置窗里能看当前置顶并一键清空。

## 三、候选窗怎么操作

| 按键 | 作用 |
|---|---|
| `1` ~ `9` | 选第几个候选 |
| `空格` | 选第一个候选 |
| `回车` | 把敲的编码**原样上屏**（`iuliqi` → `iuliqi`，不选词） |
| `←` `→` | 在当前页里左右移动选中项 |
| `-` `=` 或 `↑` `↓` | 上一页 / 下一页 |
| `Esc` | 取消，什么都不上屏 |
| `Ctrl` + `1`~`9` | 选第几个候选，**并把它置顶到这个编码**（再按一次取消） |
| **鼠标点击** | 直接点候选词就上屏；点了不会让输入框失焦 |

**候选数量按码长自动收敛**：打一个键给 18 个（2 页），两个键给 45 个（5 页），
三个键以上才给满 90 个。第一个键不会甩给你十页生僻字。

**它绝不自动上屏。** 只有你按空格 / 数字 / 回车 / 标点，字才会写进文档。

### 长句：自动分词 + 逐段选

打一长串、整串又查不到词时（比如 `nihaoshijie`），飞鹤会把它切成几段挂起来：

```text
组合串显示：[你好]世界      ← [] 里是当前段
```

| 按键 | 作用 |
|---|---|
| `←` `→` | 移到上一段 / 下一段 |
| `1` ~ `9` | 给当前段换词（候选窗显示的是这一段的候选） |
| `空格` | 确认当前段并跳到下一段（最后一段则整体上屏） |
| `回车` | 一次性整体上屏 |
| **`退格`** | **拆开当前段（词 → 单字）**，拆不动了才退掉最后一个音节 |
| 继续敲字母 | 延长组合串并重新分段，已选过的段会保留 |

**退格拆词**是最有用的一把：自动分段只会挑「词库里能匹配上的最长词」，
比如 `tsirll` 会被切成 `[通传]两`。如果你要的是「通」+「传」+「两」，
按一次退格把 `通传` 拆成两个字，候选窗立刻变成「通」的字候选，选完自动跳到「传」。
**这一步不丢编码**，再按一次退格才真的删掉末尾音节。

### 手动分隔

自动切分还是不理想时，可以用 `'` 强制断一刀：

- 全拼 / 小鹤双拼：`;`（如 `xi'an`）
- 微软双拼：`'`（分号被 `ing` 占了）

分隔符只帮你切，**不会进文档**。

## 四、快捷输入（先敲 `/`）

按 `/`（问号那个键），后面接命令码。**只打首字母也行**：
`/r` 就等于 `/rq`。只打一个 `/` 会列出所有命令的当前值，用数字挑。

| 输入 | 得到 |
|---|---|
| `/rq` | `2026年10月23日` / `2026-10-23` / `2026/10/23` / `2026.10.23` / `10月23日` / `23日` |
| `/sj` | `17:40` / `17:40:06` / `下午5点40分` / `下午5:40` |
| `/xq` | `星期四` / `周四` |
| `/dt` | `2026-10-23 17:40:06` / `… 17:40` / `2026年10月23日 17:40` / `… 星期四` |
| `/ts` | Unix 秒 / Unix 毫秒 |
| `/nl` | 农历：`农历丙午年九月十四` / `丙午年九月十四` / `九月十四` |
| `/gz` | 干支四柱：`丙午年 戊戌月 庚午日 壬午时` / `丙午 戊戌 庚午 壬午` / 不带时的三柱 |
| `/jq` | 下一个节气：`2026年11月7日 立冬` / `11月7日 立冬` / `立冬` |

### 农历 / 干支 / 节气说明

- **`/nl` 农历**：按农历年输出干支年（**按春节换年**）。闰月会写成「闰六月」。
- **`/gz` 干支**：这是**四柱（八字）**，不是农历年。年柱**按立春换**、月柱**按节气换**、
  日柱**按子时（23:00）换日**。所以春节前后几天、立春前后几天，`/nl` 和 `/gz` 的
  年份会不一样——这是对的，两者本来就是两套历法。
- **`/jq` 节气**：给你**最近的下一个**节气，精确到日。如果今天正好是节气当天，
  给的就是今天这个。

> 农历 / 干支 / 节气的计算统一来自 [Tyme](https://6tail.cn/tyme.html)（MIT 许可），
> 节气算法引自寿星天文历。三个功能共用同一套儒略日，不会互相打架。

> 为什么引导符是 `/`：顿号只留 `\` 一个键（搜狗习惯）就够了，`/` 位置好记好按，
> 拿来当功能入口更划算。中间一度搬到反引号，但那个键太偏、记不住，又换回来了。
>
> 代价是中文态下 `/` 不再出顿号。想打半角斜杠：敲 `/` 再按**回车**——
> 只敲了引导符本身时，回车会把它原样上屏（`/` 或全角的 `／`）。

## 五、状态浮窗与设置

屏幕右下角有一条小横条（可以拖动，位置会记住；也可以让它跟随光标）：

| 按钮 | 作用 |
|---|---|
| 中 / 英 | 切换中英文 |
| 全 / 半 | 切换全角 / 半角标点 |
| 符号 | 打开符号软键盘（9×5 网格，点击即插入） |
| 设置 | 打开设置窗口 |

设置窗口里能改：

- **输入模式**：双拼 / 全拼
- **双拼方案**：小鹤 / 微软
- **辅助码**：关闭 / 自然码 / 小鹤音形（`Tab` 进入辅助码筛选）
- **皮肤**：浅色 / 深色 / 护眼
- **字形**：简体 / 繁体
- **全角标点**（默认开）
- **浮窗跟随光标**
- **UILess 模式**（见下）
- **动态调频**（按你实际选词调整候选顺序）+ **重置**
- **置顶**：看当前置顶了哪些码 + 一键清空
- **词库**：统计、导入、导出、编译成二进制

### UILess 模式：全屏游戏 / 远程桌面用

打开设置里的 **UILess**，飞鹤就**一个窗口都不弹**——没有候选窗，也没有右下角那条浮窗。
它只依赖输入框自己的组合串（那是应用画在界面里的，不是我们弹的窗口），所以在这种环境下
仍然能用：

- 独占全屏的游戏
- 远程桌面 / 虚拟机控制台
- 任何「弹出来的窗口看不见、或者一弹就抢焦点」的程序

**候选去哪了？** 塞进组合串里了。打 `nihc` 会看到：

```text
nihc  1.你好 2.拟好 3.你号 …
```

数字键照样选，`-` `=` 照样翻页，空格出第一候选。没有候选窗可点，所以**鼠标选词在这个模式下不可用**。

**怎么切回去**：按 `Ctrl+Shift+U`。浮窗被藏起来了，所以这是唯一的键盘出口——
浮窗上的「设置」按钮是进设置窗的唯一入口，不给快捷键的话打开 UILess 就把自己锁在外面了。
（万一真锁住了：把 `%APPDATA%\Feihe\config.ini` 里的 `uileless=1` 改成 `0`。）

> **做不到的**：如果某个游戏完全不支持 Windows 的 TSF 输入框架（很多独占全屏的
> DirectX 游戏就是这样），那连组合串都不会有，飞鹤在里面一个字也打不出来。
> 那种场景需要「键盘钩子 + 模拟按键」的外挂式工具，飞鹤目前不做——
> 这类工具要常驻监听全部按键，风险和维护成本都远超收益。

## 六、词库

内置 3.8 万条常用词、8006 个单字（《通用规范汉字表》可编码的全收，再补 GB2312 独有的字）。
够日常，但**不是「什么都有」**——专业术语、网络新词、人名地名基本查不到，可以自己补：

1. **导入搜狗个人词库**：设置窗 → 「导入词库…」，选搜狗用户目录里的词库文件；
   也可以手工准备一个「每行 `词<TAB>全拼`」的文本再导入。
2. **编译成二进制**：导入后会自动编译；手改过文本的话点一下「编译成二进制」。
   二进制版本走内存映射，多个程序共用一份，更省内存也更快。
3. **动态调频**：你选了哪个词，下次它就往前排。不想要就在设置里关掉，或点「重置」。

用户词库的源文件在 `%APPDATA%\Feihe\user_dict.txt`，可以手工编辑、可以导出。

## 七、标点与符号

中文模式下，不带 Shift 的那一排标点键输出全角标点。

| 键 | 输出 |
|---|---|
| `,` `.` `;` `:` `?` `!` | `，` `。` `；` `：` `？` `！` |
| `(` `)` `[` `]` | `（` `）` `【` `】` |
| `\` | `、`（顿号只留这一个键） |
| `Shift + \` | `\|`（交给应用自己出） |
| `/` | 不是标点，是快捷输入的引导符 |

组合串还没上屏时按标点键，会先把候选上屏、紧跟着粘上全角标点，
**不会**出现「，,」两个字符。

## 八、常见问题

**装了但输入法列表里没有「飞鹤拼音」**
键盘列表由外壳缓存，注销一次或重启。仍然没有的话，用管理员权限重跑一遍安装包。

**首次运行被 SmartScreen 拦住**
安装包没有代码签名。点「更多信息 → 仍要运行」。

**候选窗位置不对 / 不跟着光标走**
设置里关掉「浮窗跟随光标」试试；某些全屏程序或游戏里候选窗位置由宿主决定。
如果候选窗干脆看不见、或者一弹出来就把游戏切到窗口模式，打开 **UILess 模式**。

**在游戏里完全打不出字**
先试 UILess。还是不行，说明这个游戏没接 Windows 的 TSF 输入框架——飞鹤是标准 TSF
输入法，接不进去的窗口它管不了（详见「UILess 模式」一节的说明）。

**改了双拼方案，别的程序没立刻变**
已经打开的进程要重新激活一次（点一下那个窗口）才读到新配置，不用重启。

**安装目录里有一堆 `feihe.dll.old-*`**
覆盖安装时旧 DLL 常被输入法进程占着，只能改名等重启删。重启后可手动删除，
不影响使用。

**想彻底卸载**
「设置 → 应用 → 已安装的应用 → 飞鹤拼音 → 卸载」，或运行安装目录里的 `uninstall.exe`。
卸载会清掉 COM / TSF 注册和安装目录，但**不会删你的个人数据**（见下）。

## 九、数据与隐私

- **不联网**。程序里没有任何网络代码（连导入表里都没有 `wininet` / `winhttp` / `ws2_32`），
  不是「承诺不上传」，是「没写这个功能」。
- **不要账号**，没有广告，没有热点推送。
- 你的数据全在 `%APPDATA%\Feihe\` 下：

| 文件 | 内容 |
|---|---|
| `config.ini` | 设置项 |
| `freq.txt` | 动态调频的学习记录（纯文本 `词<TAB>次数`，删掉即重置） |
| `pinned.txt` | 手动置顶（纯文本 `编码<TAB>词`，删掉即全部取消） |
| `user_dict.txt` | 你的个人词库（源文件，可编辑） |
| `user.bin` | 上面那个文件编译出来的二进制 |

卸载不会动这个目录。想彻底清干净，卸载后手动删除 `%APPDATA%\Feihe` 即可。
