Design

它占优的地方，都是「少」带来的

没有一项是靠堆功能赢的。省掉的东西，最后都变成了体积、启动速度和可读的代码。

词库零解析

构建期把 3.8 万条预编码成三套码（小鹤 / 微软 / 全拼），连同偏移表写成一个扁平文件， 用 include_bytes! 嵌进 DLL 的 .rdata。运行时只是「读两个数组 + 二分」。

多进程共享物理页

.rdata 由 PE 加载器 mmap，记事本、Word、浏览器打开同一个输入法， 词库在内存里只有一份。不是每进程各背一份私有堆。

没有联网代码

这不是隐私承诺，是「没写这个功能」。实测 18 个导入 DLL 全是 kernel32 / user32 / ole32 / CRT 这一层， 没有 wininet、winhttp、ws2_32。 用 objdump -p 一眼可验。

不自动上屏

只有你按空格 / 数字 / 回车 / 标点，字才落进文档。长句切成分段让你一段段选， 绝不替你猜一半先写进去。自动组出来的词不对，按退格能把它拆回单个字。

生僻字不缺

《通用规范汉字表》可编码的 7896 字全收，再补 GB2312 独有的 110 字（嬲、欷、榘、 以及 忄 亻 扌 这类部件）。姓「佟」的人能打出自己的姓。

一简、二简都有

一个键出最常用的字（d → 的），每个键还有次选（d; → 打）； 两个键出一个常用词（nd → 难道，370 条按小鹤官方表）。 词表是纯文本，删一行就少一个。

动态词频

你选了哪个词，下次它就往前排。稳定排序，没学过的词相对顺序一点不动， 不会因为开了这个功能把候选搞乱。

候选窗点得动

鼠标直接点候选词就上屏。窗口用 MA_NOACTIVATE 响应，点了不抢输入框焦点； 按下和抬起必须落在同一项才算数，拖出去就取消。

候选不堆山

候选数按码长衰减：单键 18 个（2 页）、两键 45 个、三键以上才满 90。 打第一个键时不会先甩你九页没用的字。

不写临时文件

运行期不留诊断日志、不往 %TEMP% 写 trace。磁盘上只有 %APPDATA%\Feihe 下的 config.ini 和 freq.txt。

简繁零体积

走 Windows 自带的 NLS 映射（LCMapStringEx），不带外部字表， 不增加安装包体积。转换失败时原样输出简体，绝不吞字。

全角标点跟手

\ 或 / 出顿号（搜狗 / 微软两种习惯都照顾）， Shift+\ 出 |。组合态按标点不会出现「，,」两个字符。

改一行就能重编

不喜欢候选顺序、想加快捷输入命令、想换皮肤颜色，改 Rust 源码，30 秒出包。 不用等官方发版。

Getting started

怎么跑起来

需要 Rust、llvm-mingw（解压到 C:\llvm-mingw）、以及 gnullvm target。 不需要 MSVC，也不需要 CMake。 

# 1. 准备 target（国内直连不通时用中科大镜像）
rustup target add x86_64-pc-windows-gnullvm
rustup target add i686-pc-windows-gnullvm

# 2. 一键构建：64 + 32 位两份 DLL，自动校验 PE 头并跑加载冒烟测试
powershell -ExecutionPolicy Bypass -File build.ps1

# 3. 打安装包（发布模式，排除本机个人词库）
powershell -ExecutionPolicy Bypass -File installer\build_setup.ps1
# → dist\Feihe-Setup-0.2.0.exe

为什么要两份 DLL

in-proc COM 的位数必须和宿主进程一致。64 位宿主加载 feihe.dll， 32 位 Office 之类加载 feihe32.dll，同一个 CLSID 背后挂两个文件。

安装后要手动加一下

到「设置 → 时间和语言 → 语言和区域 → 中文 → 语言选项 → 键盘」里应出现「飞鹤拼音」。 列表由 shell 缓存，没刷新就注销重登一次。安装目录里有 使用帮助.md， 所有键位和快捷输入都写在里面。

未签名，会撞 SmartScreen

首次运行提示「已保护你的电脑」，点「更多信息 → 仍要运行」。 要消掉得买代码签名证书，暂时没买。
